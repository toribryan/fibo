# @workspace/docs-blocks

Docs building blocks shared by Storybook and the docs site: foundations
tables and scales, guidelines, do's and don'ts, install commands and data
attribute tables. They render props only, so they work in either app.
Blocks that depend on Storybook (`DocLink`, `Canvas`, `ArgTypes`) stay in
`apps/storybook/src/blocks/`. See `plans/016-docs-site.md`.
