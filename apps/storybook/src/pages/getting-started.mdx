# Getting started

fibo is a shadcn registry. Installing a part copies its source into your
project, where it uses your tokens and you can edit it like any other file.

## Add the registry

Point shadcn at the `@fibo` namespace once, in your project's `components.json`:

```json
{
  "registries": {
    "@fibo": "https://fibo.toribryan.com/r/{name}.json"
  }
}
```

Projects started from `toribryan/design-project-template` already have this entry.

## Install a component

Add parts by name. Anything a part imports from another fibo part comes with it.

```bash
pnpm dlx shadcn@latest add @fibo/button
```

Without the namespace, the full URL works in any shadcn project:

```bash
pnpm dlx shadcn@latest add https://fibo.toribryan.com/r/button.json
```

## Use it

Components land in `components/ui` and import your own `cn` helper.

```tsx
import { Button } from "@/components/ui/button"

export function Save() {
  return <Button>Save changes</Button>
}
```

<Tip>
  The installed file uses semantic tokens such as `bg-primary` and
  `text-muted-foreground`, so it follows your theme. Any token it needs that a
  stock shadcn theme lacks, such as `--primary-hover` or `--ring-subtle`, is
  added to your `globals.css` with it, and your existing tokens are left alone.
</Tip>

## Use fibo's theme

To make the parts look the way they do here, add the full token set, light and
dark:

```bash
pnpm dlx shadcn@latest add @fibo/theme
```

This replaces your `:root` and `.dark` colour values with fibo's.

## Theming

Every colour is a semantic role that aliases a primitive ramp. Retheming means
editing `:root` and `.dark` in `globals.css` and nothing else. The toolbar's
theme switch at the top of this page flips the same `.dark` class.

## With coding agents

- [`llms.txt`](https://fibo.toribryan.com/llms.txt) lists every part with its
  install command, so an agent can pick parts without guessing names.
- With `@fibo` in `components.json`, the
  [shadcn MCP server](https://ui.shadcn.com/docs/mcp) can browse and install
  fibo parts. Add it with `pnpm dlx shadcn@latest mcp init`.

## Run it locally

```bash
pnpm install
pnpm storybook
```

Storybook runs at `localhost:6006`. The repo layout and the registry build are
documented in `AGENTS.md`.
