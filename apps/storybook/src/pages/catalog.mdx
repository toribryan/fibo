# Catalog

Every fibo part, grouped by job. Each card opens its full docs page.

## Base components

The parts most interfaces need. They depend on nothing beyond Base UI,
`class-variance-authority` and `lucide-react`.

<Catalog tier="base-components" />

## Special components

Playful parts built for one kind of moment, such as a diagram, a reading rail
or a reaction. Some use the `motion` library, which installs along with them.
