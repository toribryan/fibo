# Changelog

Notable changes, newest first.

## October 2026

- New **Tabs** in Base components, under Navigation: `Tabs`, `TabsList`,
  `TabsTrigger` and `TabsContent` on Base UI. The list is a segmented
  control by default, with the active tab on a raised pill that slides
  between tabs, or `variant="line"` for an underline. Two sizes, vertical
  lists, and a row that scrolls sideways rather than wrapping. **Rich text
  editor** is no longer marked new.
- **Calendar** has a month view: `type="month"` fills its parent with a
  month of `events`, two per cell and a count of the rest, with Today,
  Previous and Next in the header and the selected day's events listed
  beside the grid. When the calendar itself is narrow, the list moves
  below and the cells shrink to dots. Children go in the header as actions.
- New **Calendar** and **Date picker** in Base components, under Forms. The
  calendar picks a day or a range, with the whole keyboard model and a range
  bar that previews as you go. Date picker brings `DatePicker` and
  `DateRangePicker`: a popover with presets, two months and Apply on
  desktop, and a drawer with a scrolling calendar on phones. **Separator**
  and **Input group** are no longer marked new.
- New **Rich text editor** in Base components, under Forms: headings, bold,
  italic, lists, quotes and links from a toolbar or Markdown shortcuts, with
  an optional character limit. It runs on Tiptap, the second named
  dependency a base part may have after Data table's TanStack Table.
  **Empty state** is no longer marked new.
- Three new pages under **Foundations**: **Spacing**, **Elevation** and
  **Motion**, each with the steps, levels or durations fibo's parts use and
  where they use them.
- **Floating nav**'s glass lens lifts off the bar as you change items, like
  iOS: it grows, clears and magnifies, then settles on the new item. The
  phone nav on this site is glass now.
- **Floating nav** comes in liquid glass: `variant="glass"` gives a clear bar
  that bends the page behind its edges, with a glass lens that slides to the
  current item.
- **Data table** shows skeleton rows while `loading` is set, shaped like its
  columns and the same height as the rows that replace them.
- New **Empty state** in Base components, under Feedback: a title, a line
  on why, and what to do next. **Data table** shows one when it has no rows,
  with Clear filters when a search or filter hid them. **Message list**
  shows one before the first message, and **Command menu** and **Filter
  menu** draw their no-results line with it. **Field** is no longer marked
  new.
- New **Input group** in Base components, under Forms: an input with an
  icon, text or button beside it, drawn as one field. The searches in
  **Command menu**, **Filter menu** and **Data table** are built from it.
  **Count** is no longer marked new.
- New **Separator** in Base components, under Display: a rule across or
  down, with an optional label. **Message list** draws its day dividers with
  it. **Status dot** is no longer marked new.
- **Jump bar**, **Command menu**, **Filter menu** and **Reactions** draw
  their buttons with **Button** and their tick boxes with **Checkbox**'s look,
  so they focus, hover and size like everything else. Command menu's page
  label is a **Badge**.
- **Progress** comes as a circle too: `type="circle"`, small enough for a
  button. **Toast** and **Chat composer** show it while they wait, in place
  of their own spinning icons, and it's what the Spinner codemod now writes.
- New **Field** in Base components, under Forms: a label, a description
  and an error wired to one control, with no ids to match up. **FieldGroup**
  sets the size of a whole form, and **Input**, **Select** and **Switch**
  follow it. **Slider** gets a label and a live value above its track.
  **Voice memo** is no longer marked new.
- New **Count** in Base components, under Display: 99+, 1.2K or +4, read
  out in full. **Reactions**, **Jump bar**, **Filter menu**, **Data table**
  and **Sticker avatar** use it, so counts look and read the same
  everywhere. **Map pin** is no longer marked new.
- New **Status dot** in Base components, under Display: present, away or
  offline, told apart by shape. Put it in an **Avatar**, a **Sticker
  avatar** or a **Badge**. Sticker avatar's `status`, `statusLabel` and
  `statusColor` still work but are deprecated in favour of the child.
- **Command menu** has an `inset` variant: a muted shell holds the search
  box and keyboard hints, and the list sits in a card inside it.
- **Data table** keeps selected rows selected when a search or filter hides
  them, and says so: “5 members selected, 2 hidden by filters”, in the
  toolbar, the announcement and the footer count. Bulk actions act on every
  selected row, hidden ones included, and Delete's description gives the
  count. Rows a refetch drops still leave the selection.
- **Integration visual**, **Pixel snail** and **Token flow** keep resting
  off screen when you pass them a `ref`. Before, your ref replaced the one
  they watch the viewport with, so they ran everywhere. The registry ships
  the small `mergeRefs` helper they share into `lib/`.
- **Reactions** shades its flying emoji with a new `--particle-shadow`
  token, the same in both themes, instead of a colour written into the
  code. The registry ships the token with the part.

- **Data table** runs on TanStack Table. `useDataTable` takes your rows and
  columns, and the table sorts, searches, filters and pages them itself.
  Heads sort from a button, a search field and facet filters with counts sit
  in the toolbar, Columns shows and hides columns, and the footer's
  pagination follows the table. `useSearchParamsAtom` keeps sorting, filters,
  the search and the page in the URL, so a link opens the same view. Ticking
  a row re-renders that row and the toolbar, not the whole table. The
  `rowIds` and `value` props and hand-written rows still work, on the same
  table, until 0.3.0; a codemod lists every use, and the docs page has a
  migration section.

- **Command menu** scrolls only its list to the highlighted row. Before, a
  menu partly off screen pulled the page to itself as its highlight moved.
- **Sticker avatar** casts its shadow with a new `--sticker-shadow` token,
  bakes again when `--sticker-edge` changes, and keeps only the 64 most
  recent stickers in memory.
- **Integration visual** and **Pixel snail** rest while they're off screen.
  A preview clip pauses if reduced motion turns on after it started, and
  tools that share a title no longer collide.
- **Reactions** cancels particles it hasn't thrown yet when it unmounts, and
  takes its particle layer off the page once the last one lands.
- **Token flow** settles on the new value when motion turns off mid-scramble.
- **Floating nav** marks a current button item with `aria-current="true"`;
  `"page"` stays on links.
- **Message list** shows a continuation row's time when the row is tapped.
- **Table** names its scroll region or the table, never both, and a caption
  names the region when there's no `aria-label`.
- **Pagination** keeps its page on the last one when the page count shrinks,
  so it doesn't jump back when the count grows.

- **Voice memo** keeps the transcript when `lang` changes mid-recording, and
  says "Couldn't copy" when the clipboard turns the copy down.
- **Chapter scrubber** fits its preview to the screen: where neither side has
  room, as on a phone, it opens on the roomier side and narrows to fit, and it
  closes once the rail scrolls out of view. Its options take focus themselves,
  so the listbox no longer points at them with `aria-activedescendant`.
- **Reactions** takes a `locale` for its shortened counts, English by
  default, so the server and the browser write the same text.
- **Command menu** reads stored recents after it mounts, so hydration
  matches, and takes `modal`: `false` opens it without locking the page's
  scroll or moving focus, for a menu inside a card or a cover.
- **Token flow** takes `orientation`, and `vertical` stacks the tiers at
  every width.
- **Data table** rows take a `label` for their checkbox when no primary or
  person cell names them. Selection is announced once it lands, so a change a
  controlled parent turns down isn't, and unticking a row while every match is
  selected says the selection is now this page only.
- The data attributes tables for **Voice memo**, **Map pin**, **Command
  menu**, **Reactions** and **Sticker avatar** list every `data-slot`.

- **Voice memo** starts and ends a session however `recording` changes, so
  `defaultRecording` and a parent's own stop now date the memo and call
  `onComplete`. A microphone error switches the device off, and closing the
  transcript hands focus back to the device.
- **Select** no longer animates its popup under reduced motion.
- **Data table** keeps its callbacks stable across renders, so rows re-render
  less, and no longer pulls focus back in after you've left it.
- **Filter menu** scrolls only its list to the highlighted row, never the
  page.
- **Chapter scrubber** calls `onActiveChange` only when the active chapter
  changes.
- **Jump bar** notices messages added after it mounts.
- **Floating nav** re-measures its labels when they or its size change, and a
  hidden bar no longer catches taps.

- **Voice memo** tidies what the browser hears. Each settled phrase drops
  filler sounds and words said twice, capitalises "I" and each sentence, and
  ends with a full stop, or a question mark when it opens like a question.
  `tidyPhrase` is exported for text from your own service.
- **Voice memo**'s raised wordmark no longer shows crossing outlines where
  its letters overlap. Its edges are drawn from the word's merged shape, lit
  from the top left.
- On phones, this site's floating nav is compact, and its **Menu** lists
  places instead of stories: pages, shelves, groups and components. Tapping a
  component opens its docs, the page you're on is highlighted and scrolled
  into view, and rows no longer stay lit after a tap.
- **Typography** is a single page under Foundations, like Colors, with
  the scale, weights and mono on it, instead of a folder holding one story.
- The sidebar is grouped. **Foundations**, **Base components** and
  **Special components** are section headings. Base parts sit in folders by
  what they do: Actions, Forms, Display and so on, in the same order as the
  Catalog; special parts sit straight under their heading. Base component
  links now include the group, such as `base-components-forms-input--docs`;
  old links still open the right page.
- New **Voice memo** in Special components, inspired by clip-on memo
  recorders: an aluminium device that writes down what you say.
  Press it and a transcript opens beside it, filling in as you talk; press
  it again and the transcript stays, ready to copy or download as a
  Markdown file with a timestamp on each phrase. It uses the browser's
  speech recognition, or shows text from your own service.
- **Data table** is no longer marked new.
- **About fibo** tells his story the way the lore page on toribryan.com does:
  the puzzle's four rules, an animated diagram of the rabbits month by month,
  and the sequence in four lines.
- Component docs pages show their **Examples** right after Installation, with
  Usage, Anatomy and Guidelines under them.
- Component docs pages link to their component in the **Figma library**,
  for the 21 parts that have a Figma page so far.
- **Typing indicator** dots no longer get clipped at the top of their
  bounce.
- New **Map pin** in Special components: a dot, an icon or a labelled
  pill for a point on a map, in fibo's five status colours, with a preview
  card of image, meta, title, description and your own content that springs
  open on click or tap. It brings no map of its own; render it inside
  Mapbox, MapLibre or any map library's marker.
- **Floating nav** items can be text: leave out an item's `icon` and its label
  always shows, for a bar of two or three places named in words.
- **Floating nav** no longer snaps at the end of a move when it sits inside
  a zoomed or scaled container, such as a preview card. The current label
  now grows to a width measured in CSS pixels.
- Docs pages can split into **Design** and **Build** tabs. Chat composer is
  the first: Design covers its visual anatomy, spacing, states and
  arrangements; Build holds installation, usage and the API. "On this page"
  follows the open tab, and the choice is remembered.
- New **Chat composer** in Base components, under Forms. It's the first part
  built from composable pieces: a provider holds the draft, and a frame,
  header, input, footer, actions and send button compose around it in any
  order. Swap the provider to keep the draft somewhere else.
- **Data table** works on a phone. Under 32rem the table scrolls under an
  icon-only toolbar, with sort and filters in a sheet, or with
  `narrowLayout="cards"` each row becomes a card. That finishes plan 003.
- **Sheet** takes `keepMounted`, so the controls in a closed sheet keep
  their state.
- **Data table** has its toolbar: filters and create actions while idle,
  swapping in place to the selection, Select all matching and bulk actions
  while rows are selected. Bulk actions keep one order, with Delete last.
- New **Data table** in Base components, matching the Figma library: a
  checkbox column with select all and Shift+click ranges, six cell types,
  locked rows that say why, and columns pinned to either edge. The toolbar,
  bulk actions and narrow layouts follow in plan 003.
- New **Table** in Base components: native table parts at the Figma
  density, 36 pixel headers and 40 pixel rows, that scroll sideways in their
  own box. Data table builds on it.
- **Checkbox** shows its indeterminate state: a filled box with a dash.
- New **Pagination** in Base components: Previous and Next around the page
  count, with the range of rows showing, such as “1 to 25 of 10,000 members”.
- New **Sheet** in Base components: a panel that slides in from any edge
  and can be swiped away, for focused tasks and for filters on a phone.
- New **Menu** in Base components: a short list of actions from a button,
  with checkbox and radio items, submenus and a destructive item for Delete.
- New **Tooltip** in Base components: a short label on hover or focus, for
  icon buttons and for saying why something is locked. It's the first part
  of the Data table work in plan 003.
- New **Jump bar** in Base components: a bar for unread messages above, with
  "Mark as read", a pill for new messages below, and a bar for getting back
  to the present from history. Counts stop at 99+ on screen and are read out
  in full, and jumping moves focus to the message, never leaving it on a bar
  that has gone.
- **Message list** marks where unread messages begin with `unreadFrom`: a red
  line labelled "New" that breaks the group and shares a line with the date
  when a day starts there.
- New **Message list** in Base components: a conversation that groups each
  person's messages under one heading. Every reason a group breaks (a new
  author, a new day, a reply, a system or deleted message, a divider, the
  time window) is a named rule, and the window can be rolling or fixed. The
  whole list is one tab stop: arrow keys move between messages, Enter goes
  into one, Escape comes back out.
- New **Typing indicator** in Base components: says who's typing in a
  conversation, naming up to three people before switching to "Several
  people". It leaves out the person looking, takes its sentence from one
  formatter you can translate, waits for typing to settle before a screen
  reader hears it, and keeps its row when nobody is typing so the messages
  don't jump.
- **Property tokens** for the status colours: `text-success`,
  `border-success` and `fill-success` now read `--success-text`,
  `--success-border` and `--success-icon`, and the same for destructive,
  warning and info. Class names don't change. Each is held to the contrast
  its property needs, 4.5:1 for text and 3:1 for borders and icons, and a
  unit test checks every one in both themes. The Colors page explains them.
- New **Sticker avatar** in a new Display group of Special components: an
  avatar cut out like a die-cut sticker. A transparent image gets a white
  paper edge that follows its shape, a photo with a background becomes a round
  sticker, and with no image the initials are the sticker. Each one tilts by a
  stable angle from the name and lifts on hover, and status is a small sticker
  of its own told apart by shape: present, away or offline. It adds
  `--sticker-edge` and `--sticker-ink`, two tokens that keep their values in
  dark mode on purpose.
- The **Theme creator** is archived. fibo is about its components and their
  tokens, and a theme builder is a separate product. The page is off the
  site, links to it open Colors, and its code is kept in the repo under
  `archive/` in case it comes back.
- **Floating nav** has a compact size: `size="sm"` gives 36px items and
  16px icons, for sites where the bar should take less of the screen.
- **Badge** has `success`, `warning` and `info` variants, and **Input** has a
  `size` prop with `sm` for dense forms, both matching the Figma library.
- **Reactions** takes `type="inline"` or `type="floating"` in place of
  `variant`, the name the Figma component uses.
- **Integration visual** drops its `size` prop, and **Chapter scrubber** drops
  `preview="none"`. Neither had a Figma counterpart.
- The success, warning and info tints are lighter in light mode, so their
  text clears AA contrast at badge size.
- fibo can now **retire a part** without surprising anyone who installed it.
  A deprecated part carries a red pill in the sidebar and catalog, a banner
  on its docs page with what to use instead, a notice when it's installed,
  and a codemod that rewrites a project for you.
- **Spinner** is the first through it: it ships deprecated in favour of an
  indeterminate **Progress**, and is removed in 0.3.0. Run the codemod on its
  page to migrate.
- New **Floating nav** in Special components: a pill of destinations that
  floats above the bottom of a phone screen. The current item slides open to
  show its name, and the bar can step aside while the page scrolls down.
- On phones, this site now gets around with a floating nav instead of
  Storybook's bottom bar: Home, Start, Components and About, plus Menu for
  every page.
- New **About fibo** page: fibo's lore, from Fibonacci's rabbits to
  the pixel rabbit and the sunflower, and where to find him on the site.

## September 2026

- New **Command menu** in Special components: a Cmd+K or Ctrl+K palette
  where items open pages of their own, recent commands come first, search
  ranks every command across pages, and a side pane previews the highlighted
  one. It adds a `--backdrop` token for the scrim behind dialogs.
- **Getting started** is now a step-by-step walkthrough for designers of
  what the registry is, how to add, use and update parts, and how it works,
  with a picker that shows exactly what each part brings into a project.
- Installing a part from the registry now brings the tokens it uses that a
  stock shadcn theme lacks, so hover states, focus rings and status colours
  work in any project. **Theme** installs fibo's full token set with
  `shadcn add @fibo/theme`, and CI installs every part into a fresh app to
  keep it that way.
- fibo is now a **pixel rabbit**, after the rabbits in the puzzle that
  started the Fibonacci sequence. On the Welcome page he builds himself up,
  idles and hops, watches the pointer, flinches when poked and hides behind
  his ears when rage clicked. He is also the sidebar logo and the favicon.
  The **Pixel snail** stays on as the loading component.
- The Welcome page hero keeps its golden construction but no longer draws
  the spiral, and its heading and drafting labels are set in Geist.
- The **Design skills** tree groups skills by workflow phase, from Discover
  to Tell plus the brand, motion and marketing tracks, with a Folders view for
  the repo layout.
- New **Design skills** page: a file tree of every skill and reviewer agent
  in the design-skills collection, with the selected file rendered beside it
  and a button to copy its raw markdown. It reads the files from GitHub, so it
  stays current.
- **0.1.0**, the first public release.
- The two shelves are now **Base components** and **Special components**,
  formerly Components and Niche. Links to the old pages still work.
- Filter menu opens on its Search filters button by default. The always-on
  search box is `search="inline"`.
- The **Colors** page now explains the token layers and lists every semantic
  token by job, with its light and dark primitive, read from globals.css.
- New **Theme creator** under Foundations: tint the greys, set the radius,
  give primary a hue, move the status colours and swap fonts, with live AA
  checks and CSS, Figma and link exports.
- Added **Filter menu** to Niche: a menu of fields and values that turns into
  a search as you type, or slides over to one from a Search filters button.
- Added **Avatar** and **Kbd** to Display, and **Progress**, **Skeleton** and
  **Toast** to a new Feedback group.
- Added **Switch**, **Radio group**, **Select** and **Slider** to Forms.
- The light-mode input fill is lighter, so placeholder text clears WCAG AA
  contrast.
- Checkbox now dims when disabled. Its disabled styles were aimed at an
  element that never receives the attribute.
- Added **Pixel snail**, starring fibo, with a docs page on how he moves and
  responds.
- This Storybook is now the site at fibo.toribryan.com, alongside the registry
  and `llms.txt`.
- Registry items carry real titles, descriptions and docs links, and the site
  serves an `llms.txt` for coding agents.
- Lint is strict (zero warnings) in every workspace, Storybook included.
- The repo ships an `add-component` agent skill and a component reviewer.
- New **Niche** section for playful, specific parts, next to the standard
  Components. Reactions and Token flow move into it.
- Added **Integration visual**, with corner, orbit and pipeline layouts.
- Added **Chapter scrubber**, a Dock-style rail in tick or dot styles, either
  orientation.
- New docs site, modelled on monday.com's Vibe: a welcome page, a catalog,
  and component pages with usage rules, do's and don'ts, and related parts.
- Renamed the system from golden-design-system to **fibo**. The registry
  namespace is now `@fibo`.
- Added the shadcn registry build. Every component is installable from
  `fibo.toribryan.com/r/<name>.json`.
- Rebuilt the Figma library on shadcn and Base UI with Geist, one to one with
  the code tokens.
- Status tones moved to the 700 step so they clear WCAG AA on solid fills and
  on their tints.
- Added **Reactions**.
- Added **Token flow**, ported from the portfolio without its `motion`
  dependency.

- Split the token layer into primitive ramps and semantic roles.
- Added Badge, Input, Label, Textarea and Checkbox.
- Moved from a Vite scaffold to a shadcn and Base UI monorepo with Storybook.
