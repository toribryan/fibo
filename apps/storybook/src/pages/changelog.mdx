# Changelog

Notable changes, newest first.

## October 2026

- New **Tooltip** in Base components: a short label on hover or focus, for
  icon buttons and for saying why something is locked. It's the first part
  of the Data table work in plan 003.
- The **Theme creator** is archived. fibo is about its components and their
  tokens, and a theme builder is a separate product. The page is off the
  site, links to it open Colors, and its code is kept in the repo under
  `archive/` in case it comes back.
- **Floating nav** has a compact size: `size="sm"` gives 36px items and
  16px icons, for sites where the bar should take less of the screen.
- **Badge** has `success`, `warning` and `info` variants, and **Input** has a
  `size` prop with `sm` for dense forms, both matching the Figma library.
- **Reactions** takes `type="inline"` or `type="floating"` in place of
  `variant`, the name the Figma component uses.
- **Integration visual** drops its `size` prop, and **Chapter scrubber** drops
  `preview="none"`. Neither had a Figma counterpart.
- The success, warning and info tints are lighter in light mode, so their
  text clears AA contrast at badge size.
- fibo can now **retire a part** without surprising anyone who installed it.
  A deprecated part carries a red pill in the sidebar and catalog, a banner
  on its docs page with what to use instead, a notice when it's installed,
  and a codemod that rewrites a project for you.
- **Spinner** is the first through it: it ships deprecated in favour of an
  indeterminate **Progress**, and is removed in 0.3.0. Run the codemod on its
  page to migrate.
- New **Floating nav** in Special components: a pill of destinations that
  floats above the bottom of a phone screen. The current item slides open to
  show its name, and the bar can step aside while the page scrolls down.
- On phones, this site now gets around with a floating nav instead of
  Storybook's bottom bar: Home, Start, Components and About, plus Menu for
  every page.
- New **About fibo** page: fibo's lore, from Fibonacci's rabbits to
  the pixel rabbit and the sunflower, and where to find him on the site.

## September 2026

- New **Command menu** in Special components: a Cmd+K or Ctrl+K palette
  where items open pages of their own, recent commands come first, search
  ranks every command across pages, and a side pane previews the highlighted
  one. It adds a `--backdrop` token for the scrim behind dialogs.
- **Getting started** is now a step-by-step walkthrough for designers of
  what the registry is, how to add, use and update parts, and how it works,
  with a picker that shows exactly what each part brings into a project.
- Installing a part from the registry now brings the tokens it uses that a
  stock shadcn theme lacks, so hover states, focus rings and status colours
  work in any project. **Theme** installs fibo's full token set with
  `shadcn add @fibo/theme`, and CI installs every part into a fresh app to
  keep it that way.
- fibo is now a **pixel rabbit**, after the rabbits in the puzzle that
  started the Fibonacci sequence. On the Welcome page he builds himself up,
  idles and hops, watches the pointer, flinches when poked and hides behind
  his ears when rage clicked. He is also the sidebar logo and the favicon.
  The **Pixel snail** stays on as the loading component.
- The Welcome page hero keeps its golden construction but no longer draws
  the spiral, and its heading and drafting labels are set in Geist.
- The **Design skills** tree groups skills by workflow phase, from Discover
  to Tell plus the brand, motion and marketing tracks, with a Folders view for
  the repo layout.
- New **Design skills** page: a file tree of every skill and reviewer agent
  in the design-skills collection, with the selected file rendered beside it
  and a button to copy its raw markdown. It reads the files from GitHub, so it
  stays current.
- **0.1.0**, the first public release.
- The two shelves are now **Base components** and **Special components**,
  formerly Components and Niche. Links to the old pages still work.
- Filter menu opens on its Search filters button by default. The always-on
  search box is `search="inline"`.
- The **Colors** page now explains the token layers and lists every semantic
  token by job, with its light and dark primitive, read from globals.css.
- New **Theme creator** under Foundations: tint the greys, set the radius,
  give primary a hue, move the status colours and swap fonts, with live AA
  checks and CSS, Figma and link exports.
- Added **Filter menu** to Niche: a menu of fields and values that turns into
  a search as you type, or slides over to one from a Search filters button.
- Added **Avatar** and **Kbd** to Display, and **Progress**, **Skeleton** and
  **Toast** to a new Feedback group.
- Added **Switch**, **Radio group**, **Select** and **Slider** to Forms.
- The light-mode input fill is lighter, so placeholder text clears WCAG AA
  contrast.
- Checkbox now dims when disabled. Its disabled styles were aimed at an
  element that never receives the attribute.
- Added **Pixel snail**, starring fibo, with a docs page on how he moves and
  responds.
- This Storybook is now the site at fibo.toribryan.com, alongside the registry
  and `llms.txt`.
- Registry items carry real titles, descriptions and docs links, and the site
  serves an `llms.txt` for coding agents.
- Lint is strict (zero warnings) in every workspace, Storybook included.
- The repo ships an `add-component` agent skill and a component reviewer.
- New **Niche** section for playful, specific parts, next to the standard
  Components. Reactions and Token flow move into it.
- Added **Integration visual**, with corner, orbit and pipeline layouts.
- Added **Chapter scrubber**, a Dock-style rail in tick or dot styles, either
  orientation.
- New docs site, modelled on monday.com's Vibe: a welcome page, a catalog,
  and component pages with usage rules, do's and don'ts, and related parts.
- Renamed the system from golden-design-system to **fibo**. The registry
  namespace is now `@fibo`.
- Added the shadcn registry build. Every component is installable from
  `fibo.toribryan.com/r/<name>.json`.
- Rebuilt the Figma library on shadcn and Base UI with Geist, one to one with
  the code tokens.
- Status tones moved to the 700 step so they clear WCAG AA on solid fills and
  on their tints.
- Added **Reactions**.
- Added **Token flow**, ported from the portfolio without its `motion`
  dependency.

## August 2026

- Split the token layer into primitive ramps and semantic roles.
- Added Badge, Input, Label, Textarea and Checkbox.
- Moved from a Vite scaffold to a shadcn and Base UI monorepo with Storybook.
