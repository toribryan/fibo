# Colors

fibo is achromatic: grays carry structure and color only carries meaning.
Components read semantic tokens, each pointing at a Tailwind primitive per mode.

<ColorScale />

## How the layers work

Three layers. Components use only the last.

1. **Primitives** are Tailwind's palette, unchanged: `neutral-900`, `red-700`.
   fibo defines none of its own.
2. **Semantic tokens** live in `globals.css`. Each names a job, such as
   `--primary` or `--destructive`, and points at a primitive once for light
   mode and once for dark.
3. **Utilities** come from `@theme inline`, which turns every semantic token
   into Tailwind classes: `bg-primary`, `text-muted-foreground`,
   `border-border`.

```css
/* globals.css */
:root {
  --primary: var(--color-neutral-900);
}

.dark {
  --primary: var(--color-neutral-50);
}

@theme inline {
  --color-primary: var(--primary);
}
```

```tsx
<button className="bg-primary text-primary-foreground">Save</button>
```

A theme changes only the second layer. Components stay the same.

## Property tokens

Each status color has a token per property it paints: `-text` for text,
`-border` for borders and `-icon` for icons and marks. The class names don't
change. `text-success` reads `--success-text`, `border-success` reads
`--success-border`, and `fill-success` and `stroke-success` read
`--success-icon`, while `bg-success` keeps the solid fill.

One value can't meet every bar. Text needs 4.5:1 against
the surface behind it, while borders, icons and marks need 3:1. Holding each
property to its own bar lets a theme tune one without breaking another, and a
unit test fails if any of them drops below its bar in either theme. Today they
match their status color. See
[plan 003](https://github.com/toribryan/fibo/blob/main/plans/003-property-tokens.md)
for the reasoning and next steps.

## Named alpha roles

Tokens that end in `-subtle`, `-hover` or `-ring` are a color at a set alpha,
such as `red-700 at 8%`. They exist instead of opacity modifiers like
`bg-destructive/10`, because Figma can't bind an opacity to a variable. A named
role keeps the alpha in one place and gives design and code the same name.

## Primitives

The Tailwind steps fibo uses: one gray ramp for structure, and two steps of
four hues for status, 700 in light mode and 400 in dark. The rest of
[Tailwind's palette](https://tailwindcss.com/docs/colors) is available to
themes. Components never use primitives directly.
