# Themes

A theme is mostly a new set of semantic token values. fibo ships its own
achromatic look and two experimental themes, Mechanical and Electrical. The
palette button beside the sidebar's search switches theme; light and dark
switch from the top of the sidebar.

<ThemeCompare />

Each column sets its own `data-theme`, independent of the page's theme.
`data-theme="fibo"` puts fibo's own look back on a region inside a themed page.

## Mechanical

A warm, tactile theme for tools that want to feel like hardware.

- **Surfaces.** A beige page, cream cards, near-white fields, near-black
  text and sand hairlines. Dark mode is a warm near-black with slightly
  lighter cards.
- **Primary.** Terracotta, with a white label, in both modes. Hover darkens it.
- **The edge.** Buttons, select and date picker triggers, the selected tab
  in a segmented control and keyboard keys sit on a solid bottom edge and
  press down onto it like a key. Inputs stay flat and take a soft warm ring
  on focus.
- **Shape and type.** 6px corners on controls and IBM Plex Sans, with labels,
  buttons and tabs at 600.
- **Color in icons.** The chart tokens are saturated, so an icon in a menu,
  Command menu, Filter menu or Floating nav can take its own color with
  `className="text-chart-2"`. In fibo's own look the chart tokens are grays.

## Electrical

A flat, ledger-like theme for tools that deal in numbers.

- **Surfaces.** A sage page, white cards and fields, green-black text and
  green-gray hairlines. Dark mode is a green near-black.
- **Primary.** Ink with a white label in light mode. In dark mode the yellow
  highlight becomes the primary, under an ink label.
- **The highlight.** One yellow, `--highlight`, marks what is selected: the
  active segment of a tab list, the active reaction, a link's underline and
  selected text. Everything else stays green-gray, and icons stay
  monochrome.
- **Shape and type.** Flat controls with 4px corners, never pills. Inter
  Tight, with labels and buttons at 500, tight headings and tabular figures.
- **Icons.** Drawn like a schematic: a 1.25px hairline at every size, square
  ends and sharp corners. The stroke doesn't scale with the icon, so small
  icons don't fade.

## Use it

Set the attribute on `<html>` for the whole app, or on any element for one
region. Dark mode follows the `dark` class.

```tsx
<html lang="en" data-theme="mechanical">
```

Each theme's rules stop at a nested `data-theme`, so a region in another theme
keeps its own look.

The registry item adds the theme's tokens and edge rules to the global
stylesheet, scoped to the attribute, so nothing changes until it is set.

```bash
pnpm dlx shadcn@latest add @fibo/theme-mechanical
pnpm dlx shadcn@latest add @fibo/theme-electrical
```

Each theme names its font but doesn't load it: IBM Plex Sans for Mechanical,
Inter Tight for Electrical. Load it from Google Fonts, or set `--font-sans` to a
font the app already loads:

```html
<link
  rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500;600;700&family=Inter+Tight:wght@400..700&display=swap"
/>
```

## The edge tokens

Five tokens draw the edge. fibo's own values give it no depth and no color, so
the default look is flat; Mechanical turns it on.

- **`--edge-depth`**: how far a key travels. `0px` in fibo; `3px` in
  Mechanical, and `2px` on xs and sm buttons.
- **`--primary-edge`**: under the primary button. A burnt terracotta,
  `#7f3418` light and `#5c2410` dark.
- **`--secondary-edge`**: under the secondary button. `#aea99f` light,
  `#0c0b0a` dark.
- **`--outline-edge`**: under outline buttons, triggers, the selected tab and
  keys. `#b8b3aa` light, `#0c0b0a` dark.
- **`--destructive-edge`**: under the destructive button, mixed from
  `--destructive`.

All five are `transparent` or zero in fibo's own look, and in Electrical.

The theme's stylesheet targets parts by their existing data attributes:
Button's `data-variant` and `data-size`, `data-slot` on select and date picker
triggers, Tabs' `data-slot` and `data-variant`, and Kbd's `data-slot`. Ghost and link buttons stay flat.

## Make another theme

Copy `packages/ui/src/styles/themes/mechanical.css`, rename the attribute and
change the values. Override only semantic tokens, keep the dark block in
step with the light one, and add rules for shape only where a token can't say
it, each ending in the nested-theme guard. Plans 011 and 012 have
the reasoning.
