# Filter menu

A two-level filter menu, fields then values, with search across every field
and value.

<Canvas of={Stories.AppliedAsChips} />

## Features

- Two levels: pick a field such as Status, then check any number of its
  values. Each field shows a count of selected values.
- A Search filters button, or typing a letter, slides the menu to a search
  grouped by field, with matched letters in bold. Inside a field, search is
  scoped to it.
- `search="inline"` puts a search box at the top instead; typing turns the
  menu into results in place.
- Escape clears the search, then leaves the field, then closes the menu.
- Views slide forward and back, and the popup's height follows its content.
  Under reduced motion, views swap in place.

## Usage

```tsx
import { useState } from "react"
import {
  FilterMenu,
  type FilterField,
  type FilterValue,
} from "@/components/ui/filter-menu"

const fields: FilterField[] = [
  {
    id: "status",
    label: "Status",
    options: [
      { value: "todo", label: "Todo" },
      { value: "done", label: "Done" },
    ],
  },
  {
    id: "priority",
    label: "Priority",
    options: [
      { value: "urgent", label: "Urgent" },
      { value: "low", label: "Low" },
    ],
  },
]

export function IssueFilters() {
  const [filters, setFilters] = useState<FilterValue>({})
  return (
    <FilterMenu fields={fields} value={filters} onValueChange={setFilters} />
  )
}
```

The menu only picks filters; displaying applied filters is up to the app.
`value` holds chosen values keyed by field id, e.g. `{ status: ["todo"] }`.

```ts
type FilterField = {
  id: string
  label: string
  icon?: React.ReactNode
  options: { value: string; label: string; icon?: React.ReactNode }[]
}

type FilterValue = Record<string, string[]>
```

### Fitting it into your app

- `open`, `defaultOpen` and `onOpenChange` control the open state, for a
  keyboard shortcut or an external opener.
- `trigger` replaces the default button. It must forward its ref and props,
  as fibo's `Button` does.
- `side` and `align` place the popup; `container` portals it somewhere other
  than the body, such as inside a dialog.
- `popupClassName` styles the popup, which is portalled outside the
  trigger's selectors.
- `labels` replaces built-in text, alongside `triggerLabel`, `placeholder`,
  `emptyText`, `label` and `searchLabel`.

```tsx
<FilterMenu
  fields={fields}
  trigger={<Button variant="ghost" size="icon" aria-label="Filtern" />}
  label="Filter"
  searchLabel="Filter durchsuchen"
  emptyText="Keine passenden Filter"
  labels={{
    backToFields: "Zurück zu den Feldern",
    backToFilters: "Zurück zu den Filtern",
    backToField: (field) => `Zurück zu ${field}`,
    results: (count) => `${count} ${count === 1 ? "Ergebnis" : "Ergebnisse"}`,
  }}
/>
```
