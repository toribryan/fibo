# Map marker

A marker for a point on a map, as a dot, an icon or a labelled pill, with a preview
card that opens on click or tap. It brings no map of its own: your map library
places it and moves it as the map pans and zooms.

<Canvas of={Stories.Default} />

## Features

- A dot, an icon or a pill with a short label such as a price, in two sizes.
- Five colours from fibo's status roles, for when colour means something:
  open or closed, available or full.
- A preview card with an image, meta line, title and description, plus any
  content of your own, such as directions or a save button.
- Lifts on hover, part of the way to its open size, then opens on click or
  tap with a springy grow from the marker and stays open, so the card can
  hold links and actions. Escape or a click elsewhere closes it and returns focus.
- Works in Mapbox, MapLibre or any library that can place a DOM element on
  its map.

## Installation

<Install
  name="map-marker"

It installs `@base-ui/react` for the popover. Your map library is your own
dependency; fibo doesn't add one.

## Usage

With `react-map-gl`, which works with both Mapbox and MapLibre, put the
marker inside the library's own `Marker`:

```tsx
import Map, { Marker } from "react-map-gl/maplibre"

import { MapMarker } from "@/components/ui/map-marker"

export function Places({ places }: { places: Place[] }) {
  return (
    <Map initialViewState={{ longitude: -122.42, latitude: 37.77, zoom: 13 }}>
      {places.map((place) => (
        <Marker key={place.id} longitude={place.lng} latitude={place.lat}>
          <MapMarker
            label={place.name}
            meta={place.category}
            title={place.name}
            description={place.summary}
          />
        </Marker>
      ))}
    </Map>
  )
}
```

With a library that takes a plain element, render into the element you hand
it:

```tsx
const element = document.createElement("div")
createRoot(element).render(
  <MapMarker label="Blue Bottle Coffee" title="Blue Bottle Coffee" />
)
new maplibregl.Marker({ element }).setLngLat([-122.42, 37.77]).addTo(map)
```

`label` names the marker for screen readers, so give every marker one, even
when it shows a price.

## Examples

### Label markers

`type="label"` shows a short value in a pill. The open one fills in, so it's
clear which preview belongs to which marker.

<Canvas of={Stories.LabelMarkers} />

### Icon markers

`type="icon"` puts an icon in a round marker, for maps where the kind of
place matters. Without an `icon`, it shows a map pin.

<Canvas of={Stories.IconMarkers} />

### Colours

`variant` takes fibo's status colours. Here they say whether each place is
open. The status is in each marker's `label` and meta too, so it doesn't rest
on colour alone.

<Canvas of={Stories.Colours} />

### Labels with icons

A label marker can lead with an icon, and colours its text to match the
`variant`. The open one fills in.

<Canvas of={Stories.LabelsWithIcons} />

### Sizes

`size="sm"` shrinks all three types for dense maps. The dot's press area stays
32px either way.

<Canvas of={Stories.Sizes} />

### Custom content

Children go under the other fields, for actions such as directions or saving
the place.

<Canvas of={Stories.CustomContent} />

### Controlled

`open` and `onOpenChange` let a list beside the map choose the open marker.
Picking a row opens its preview; opening a marker selects its row.

<Canvas of={Stories.Controlled} />

### Without a preview

With no preview fields or children, the marker is a plain button, for maps
where a click does something else, such as filtering a list.

<Canvas of={Stories.WithoutPreview} />

### Data attributes

Style the marker by slot or state, for example with
`[&[data-slot=map-marker][data-popup-open]]:scale-150`. The preview renders in
a portal on the body, so style it with `previewClassName`.
