# Table

Table lays out rows and columns of data in a native HTML table, at one
compact density: 36 pixel headers and 40 pixel rows.

<Canvas of={Stories.Default} />

## Features

- Native `table`, `thead`, `tbody` and `tfoot`, so screen readers announce
  rows, columns and headers.
- Scrolls sideways inside its own box when it's wider than the page, and
  joins the tab order while it does so keyboards can scroll it.
- Hover and selected row states, with borders on the cells so pinned columns
  stay lined up.
- Data table builds selection, cell types and pinning on top of it.

## Usage

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui/table"

export function Members({ members }: { members: Member[] }) {
  return (
    <Table>
      <TableHeader>
        <TableRow>
          <TableHead>Member</TableHead>
          <TableHead className="text-right">Projects</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        {members.map((member) => (
          <TableRow key={member.id}>
            <TableCell className="font-medium">{member.name}</TableCell>
            <TableCell className="text-right tabular-nums">
              {member.projects}
            </TableCell>
          </TableRow>
        ))}
      </TableBody>
    </Table>
  )
}
```

Right-align numbers and their headers, with `tabular-nums` so digits line up.
For selection, pinned columns and bulk actions, use Data table.

## API reference

Every part takes the props of the HTML element it renders. Table's
`className` goes on the `table`, not the scroll box.
