# Drop zone

Drop zone wraps an area people can drop files onto, and shows an overlay
while they drag files over it. Drag a file from your desktop over the panel.

<Canvas of={Stories.Default} />

## Features

- Covers the area it wraps, usually a whole conversation panel, so the
  target is easy to hit.
- Splits dropped files by `accept` into `onDropFiles` and `onRejectFiles`.
- Has no state of its own beyond the drag. What it covers never changes.
- Ignores text and links dragged across it; only files show the overlay.

## Usage

```tsx
import { DropZone } from "@/components/ui/drop-zone"

export function ChatPanel({ addFiles, reject }: Props) {
  return (
    <DropZone
      accept="image/*,.pdf"
      description="Images and PDFs up to 25 MB"
      onDropFiles={addFiles}
      onRejectFiles={(files) => reject(files)}
      className="rounded-xl border"
    >
      <MessageList />
      <Composer />
    </DropZone>
  )
}
```

Match `accept` to the file picker's, so dropping and picking take the same
files. In a chat, `ChatComposerDropZone` passes the composer's
`addAttachments` for you.
