# Menu

Menu opens a short list of actions from a button, such as More actions on a
toolbar or the actions for one row in a table.

<Canvas of={Stories.Default} />

## Features

- Opens from a button by click, Enter, Space or the down arrow, and puts
  focus on the first item.
- Arrow keys move between items, typing a letter jumps to the item that
  starts with it, and Escape closes and returns focus.
- Items for actions, checkboxes and radio choices, with groups, labels,
  separators and submenus.
- A `destructive` item for delete and anything that can't be undone.

## Examples

### Row actions

An icon-only trigger at the end of a row. Its label names the row, so each
trigger in a table is distinct.

### Checkboxes

Items that toggle, such as which columns a table shows. The menu stays open

<Canvas of={Stories.Checkboxes} />

### Radio

One choice from a group, such as the sort order.

<Canvas of={Stories.Radio} />

### Submenu

A second level for a choice with its own options. The last item is disabled.

<Canvas of={Stories.Submenu} />

### Colored icons

An icon keeps a color you give it, such as
`<GlobeIcon className="text-chart-2" />`, so a menu of destinations reads
apart at a glance. Icons without one stay muted. The chart tokens are grays
in fibo's own theme and saturated in Mechanical.

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Menu,
  MenuContent,
  MenuItem,
  MenuSeparator,
  MenuTrigger,
} from "@/components/ui/menu"

export function MoreActions({ onDelete }: { onDelete: () => void }) {
  return (
    <Menu>
      <MenuTrigger render={<Button variant="outline" />}>More</MenuTrigger>
      <MenuContent>
        <MenuItem>Edit</MenuItem>
        <MenuItem>Duplicate</MenuItem>
        <MenuSeparator />
        <MenuItem variant="destructive" onClick={onDelete}>
          Delete
        </MenuItem>
      </MenuContent>
    </Menu>
  )
}
```

`render` makes the Button itself the trigger. Put a destructive item last,
after a separator.

## Do's and don'ts

export const StaticMenu = ({ items }) => (
  <div className="flex w-40 flex-col rounded-lg border border-border bg-popover p-1 text-sm text-popover-foreground shadow-md">
    {items.map((item, index) =>
      item === "---" ? (
        <span key={index} className="-mx-1 my-1 h-px bg-border" />
      ) : (
        <span
          key={index}
          className={
            item.startsWith("!")
              ? "px-2 py-1.5 text-destructive"
              : "px-2 py-1.5"
          }
        >
          {item.replace("!", "")}
        </span>
      )
    )}
  </div>
)

<ComponentRules
  rules={[
    {
      positive: {
        component: <StaticMenu items={["Export", "---", "!Delete"]} />,
        description: "Put Delete last, set apart and marked destructive.",
      },
      negative: {
        component: <StaticMenu items={["Delete", "Export"]} />,
        description:
          "Don't lead with Delete or style it like the rest. It's too easy to choose by mistake.",
      },
    },
  ]}
/>

## API reference

MenuContent takes every prop of Base UI's Menu Popup, plus `side`, `align`
and their offsets from the Positioner. The other parts take the props of the
Base UI part they wrap. MenuItem, MenuLabel and MenuSubTrigger also take
`inset`, and MenuItem takes `variant`.
