# Status dot

A small mark for whether someone is present, away or offline. Put it in an
avatar, a sticker avatar or a badge; the part it sits in places it.

<Canvas of={Stories.Default} />

## Features

- Told apart by shape, a dot, a crescent and a ring, so status reads without
  colour, and coloured with fibo's `success`, `warning` and
  `muted-foreground` tokens.
- A page-coloured disc behind the mark keeps a clear edge on a photo or a
  sticker.
- Says its status to screen readers, in words you can translate, and joins
  the name of a sticker avatar it sits in.
- Placed by its host: pinned to an avatar's corner, tilted on a sticker,
  leading the text in a badge.

## Examples

### Status by shape

Present is a dot, away a crescent, offline a ring.

<Canvas of={Stories.Statuses} />

### Without colour

`variant="mono"` draws the marks in the text colour, for places where
colour would compete, such as a dense list.

<Canvas of={Stories.Mono} />

### Sizes

`size` is `xs`, `sm`, `default` or `lg`: 8, 10, 12 and 16 pixels. A host
can size it too; Avatar matches it to its own size.

<Canvas of={Stories.Sizes} />

### On avatars

Put it in an Avatar or a Sticker avatar as a child. Avatar pins it to the
corner; Sticker avatar sets it on the paper, turned against the tilt, and
adds its label to the sticker's name.

<Canvas of={Stories.OnAvatars} />

### In a badge

A badge leads with it. The badge's text already says the status, so the dot
gets `label={null}`.

<Canvas of={Stories.InABadge} />

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { StatusDot } from "@/components/ui/status-dot"

export function Member() {
  return (
    <Avatar>
      <AvatarImage src="/ana.jpg" alt="Ana Ruiz" />
      <AvatarFallback>AR</AvatarFallback>
      <StatusDot status="away" />
    </Avatar>
  )
}
```

Let the dot say the status, or the text beside it, never both: pass
`label={null}` when the words are already on screen.
