# Status dot

A small presence mark, present, away or offline, placed by the Avatar,
Sticker avatar or Badge it sits in.

<Canvas of={Stories.Default} />

## Features

- Distinct shapes, a dot, a crescent and a ring, so status reads without
  color. Colored with the `success`, `warning` and `muted-foreground`
  tokens.
- A page-colored disc behind the mark keeps a clear edge on a photo or a
  sticker.
- Announces its status in a translatable label, which joins a Sticker
  avatar's name.
- Placed by its host: pinned to an avatar's corner, tilted on a sticker,
  leading the text in a badge.

## Examples

### Status by shape

Present is a dot, away a crescent, offline a ring.

<Canvas of={Stories.Statuses} />

### Without color

`variant="mono"` draws the marks in the text color, for places where color
would compete, such as a dense list.

<Canvas of={Stories.Mono} />

### Sizes

`size` is `xs`, `sm`, `default` or `lg`: 8, 10, 12 and 16px. A host can
size it too; Avatar matches it to its own size.

<Canvas of={Stories.Sizes} />

### On avatars

Pass it as a child. Avatar pins it to the corner; Sticker avatar sets it on
the paper, turned against the tilt, and adds its label to the sticker's
name.

<Canvas of={Stories.OnAvatars} />

### In a badge

The badge's text already says the status, so the dot gets `label={null}`.

<Canvas of={Stories.InABadge} />

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { StatusDot } from "@/components/ui/status-dot"

export function Member() {
  return (
    <Avatar>
      <AvatarImage src="/ana.jpg" alt="Ana Ruiz" />
      <AvatarFallback>AR</AvatarFallback>
      <StatusDot status="away" />
    </Avatar>
  )
}
```

The dot or the text beside it says the status, never both: pass
`label={null}` when the words are on screen.
