# Progress

A progress bar shows how far a task has got, such as an upload or an export.
With no value, it shows that the task is under way.

<Canvas of={Stories.Default} />

## Features

- Determinate, from 0 to 100, or indeterminate while the total isn't known,
  built on Base UI's Progress.
- A label and a formatted value sit on one row above the bar.
- Announced as a progress bar with its name and value.
- The fill glides between values, and jumps instead under reduced motion.

## Usage

```tsx
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@/components/ui/progress"

export function Upload({ percent }: { percent: number }) {
  return (
    <Progress value={percent}>
      <ProgressLabel>Uploading photos</ProgressLabel>
      <ProgressValue />
    </Progress>
  )
}
```

Pass `value={null}` while you don't know how long the task will take.

## Examples

### Indeterminate

`value={null}` for a task with no known length. A segment sweeps across the
track; under reduced motion the bar fills in the muted text colour instead.

<Canvas of={Stories.Indeterminate} />

### Complete

At 100 the bar is full and the root carries `data-complete`.

<Canvas of={Stories.Complete} />

### Without label

With no visible label, name the bar with `aria-label`.

<Canvas of={Stories.WithoutLabel} />

### Live

A controlled bar that fills as a task runs, with a label that changes when
it finishes.

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <Progress value={45} className="w-56">
            <ProgressLabel>Exporting report</ProgressLabel>
            <ProgressValue />
          </Progress>
        ),
        description: "Say what's in progress and how far it has got.",
      },
      negative: {
        component: (
          <Progress value={45} aria-label="Progress" className="w-56">
            <ProgressLabel>Please wait…</ProgressLabel>
          </Progress>
        ),
        description:
          "Don't just ask people to wait. They can't tell what's happening or whether it's stuck.",
      },
    },
  ]}
/>

## API reference

Progress takes every prop of Base UI's `Progress.Root`, including `value`,
`min`, `max`, `format` and `getAriaValueText`.

<UsageGuidelines
  guidelines={[
