# Progress

A bar showing how far a task such as an upload has got, or, with no value,
that it's under way.

<Canvas of={Stories.Default} />

## Features

- Determinate, from 0 to 100, or indeterminate while the total isn't known,
  built on Base UI's Progress.
- A label and formatted value on one row above the bar.
- Announced as a progress bar with its name and value.
- The fill glides between values; under reduced motion it jumps.

## Examples

### Circle

`type="circle"` draws a ring in the current text color, sized `xs` to `lg`:
12, 16, 20 and 24 pixels. With a `value` the arc shows progress; with
`value={null}` a quarter arc turns, holding still under reduced motion. Name
it with `aria-label`, since a circle has no room for a label.

<Canvas of={Stories.Circle} />

### In a button

A small circle replaces a button's icon while its action runs. The button's
text or `aria-label` says what's happening, so the circle is hidden from
screen readers. Used by Toast and Chat composer.

<Canvas of={Stories.InAButton} />

### Indeterminate

`value={null}` for a task of unknown length. A segment sweeps across the
track; under reduced motion the bar fills in the muted text color.

<Canvas of={Stories.Indeterminate} />

### Complete

At 100 the bar is full and the root carries `data-complete`.

<Canvas of={Stories.Complete} />

### Without label

Named with `aria-label`.

<Canvas of={Stories.WithoutLabel} />

### Live

A controlled bar whose label changes when the task finishes.

<Canvas of={Stories.Live} />

## Usage

```tsx
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@/components/ui/progress"

export function Upload({ percent }: { percent: number }) {
  return (
    <Progress value={percent}>
      <ProgressLabel>Uploading photos</ProgressLabel>
      <ProgressValue />
    </Progress>
  )
}
```

`value={null}` while the task's length is unknown.

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <Progress value={45} className="w-56">
            <ProgressLabel>Exporting report</ProgressLabel>
            <ProgressValue />
          </Progress>
        ),
        description: "Say what's in progress and how far it has got.",
      },
      negative: {
        component: (
          <Progress value={45} aria-label="Progress" className="w-56">
            <ProgressLabel>Please wait…</ProgressLabel>
          </Progress>
        ),
        description:
          "Don't just ask people to wait. They can't tell what's happening or whether it's stuck.",
      },
    },
  ]}
/>

## API reference

`Progress` takes every Base UI `Progress.Root` prop, including `value`,
`min`, `max`, `format` and `getAriaValueText`.

<UsageGuidelines
