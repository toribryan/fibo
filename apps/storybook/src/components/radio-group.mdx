# Radio group

Picks exactly one option from a short list, with every option visible.

<Canvas of={Stories.Default} />

## Features

- One choice at a time, built on Base UI's Radio group.
- Arrow keys move the selection; the group is one Tab stop.
- Each item's hit area reaches past the 16px circle to the 24px minimum.
- Disable the whole group or a single option.

## Usage

```tsx
import { Label } from "@/components/ui/label"
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group"

export function PlanPicker() {
  return (
    <RadioGroup defaultValue="pro" aria-label="Plan">
      <div className="flex items-center gap-2">
        <RadioGroupItem value="hobby" id="hobby" />
        <Label htmlFor="hobby">Hobby</Label>
      </div>
      <div className="flex items-center gap-2">
        <RadioGroupItem value="pro" id="pro" />
        <Label htmlFor="pro">Pro</Label>
      </div>
    </RadioGroup>
  )
}
```

Every item needs a unique `value`. `onValueChange` reports the chosen one.

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <RadioGroup defaultValue="monthly" aria-label="Billing">
            {["Monthly", "Yearly"].map((label) => (
              <div key={label} className="flex items-center gap-2">
                <RadioGroupItem
                  value={label.toLowerCase()}
                  id={`rule-yes-${label}`}
                />
                <Label htmlFor={`rule-yes-${label}`}>{label}</Label>
              </div>
            ))}
          </RadioGroup>
        ),
        description: "Show a short list with a sensible default chosen.",
      },
      negative: {
        component: (
          <RadioGroup aria-label="Country" className="grid-cols-3 gap-2">
            {[
              "Austria",
              "Belgium",
              "Croatia",
              "Denmark",
              "Estonia",
              "Finland",
              "France",
              "Germany",
              "Greece",
            ].map((label) => (
              <div key={label} className="flex items-center gap-2">
                <RadioGroupItem value={label} id={`rule-no-${label}`} />
                <Label htmlFor={`rule-no-${label}`}>{label}</Label>
              </div>
            ))}
          </RadioGroup>
        ),
        description: "Don't lay out a long list as radios. Use Select.",
      },
    },
  ]}
/>

## API reference

`RadioGroup` takes every Base UI `RadioGroup` prop, including `value`,
`defaultValue`, `onValueChange`, `name` and `disabled`. `RadioGroupItem` takes
`Radio.Root`'s, including `value` and `disabled`.
