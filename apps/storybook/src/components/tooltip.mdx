# Tooltip

Tooltip shows a short label when a control is hovered or focused, such as the
name of an icon button or why something is locked.

<Canvas of={Stories.Default} />

## Features

- Opens on hover after a short delay, and at once on keyboard focus.
- Escape closes it without moving focus.
- Once one tooltip is open, its neighbours in a TooltipProvider open without
  the delay.
- Flips to stay on screen, and skips its animation when reduced motion is on.

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip"

export function Save() {
  return (
    <Tooltip>
      <TooltipTrigger
        render={<Button size="icon-sm" variant="ghost" aria-label="Save" />}
      >
        <SaveIcon aria-hidden="true" />
      </TooltipTrigger>
      <TooltipContent>Save</TooltipContent>
    </Tooltip>
  )
}
```

`render` makes the Button itself the trigger, so there's one focusable
element. The tooltip repeats the trigger's accessible name; it never holds
anything the name doesn't.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Keep it to a few words: a name, a shortcut, or a short reason.",
    "Use it to name icon-only buttons and to explain a locked or disabled control.",
    "Wrap a toolbar of icon buttons in one TooltipProvider, so moving along it doesn't wait on every button.",

## API reference

TooltipContent takes every prop of Base UI's Tooltip Popup, plus `side`,
`align` and their offsets from the Positioner. Tooltip, TooltipTrigger and
TooltipProvider take Base UI's Root, Trigger and Provider props; `delay`
defaults to 600ms.
