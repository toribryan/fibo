# Tooltip

A short label shown on hover or focus, such as an icon button's name or why
something is locked.

<Canvas of={Stories.Default} />

## Features

- Opens on hover after a short delay, and at once on keyboard focus.
- Escape closes it without moving focus.
- Once one tooltip is open, its neighbors in a TooltipProvider open without
  the delay.
- Flips to stay on screen, and skips its animation when reduced motion is on.

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip"

export function Save() {
  return (
    <Tooltip>
      <TooltipTrigger
        render={<Button size="icon-sm" variant="ghost" aria-label="Save" />}
      >
        <SaveIcon aria-hidden="true" />
      </TooltipTrigger>
      <TooltipContent>Save</TooltipContent>
    </Tooltip>
  )
}
```

`render` makes the Button the trigger, so there's one focusable element. The
tooltip repeats the trigger's accessible name and never adds to it.

## API reference

TooltipContent takes every prop of Base UI's Tooltip Popup, plus `side`,
`align` and their offsets from the Positioner. Tooltip, TooltipTrigger and
TooltipProvider take Base UI's Root, Trigger and Provider props; `delay`
defaults to 600ms.
