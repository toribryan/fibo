# Typing indicator

Shows who's writing a reply in a conversation, naming up to three people,
then "Several people are typing…".

<Canvas of={Stories.Default} />

## Features

- Takes people as data and omits the current user.
- One formatter builds the whole sentence, so it translates properly. Names
  are joined with `Intl.ListFormat` for the locale.
- Announces the sentence once it settles, and stays silent when everyone
  stops.
- Keeps its height when nobody is typing, so messages above don't jump.

## Examples

### One person

### Three people

Up to `maxNames` people are named, joined for the locale.

<Canvas of={Stories.Three} />

### Several people

Past `maxNames`, nobody is named, as Discord does from four people on.

<Canvas of={Stories.Several} />

### Long names

Each name is truncated at `maxNameLength` characters so one can't push the
others off the line. Screen readers still hear names in full.

<Canvas of={Stories.LongNames} />

### Custom indicator

A person's `indicator` replaces the dots while they're the only one typing.
With two or more, the dots return, as with Discord's custom typing
indicators.

<Canvas of={Stories.CustomIndicator} />

### Translated

A Spanish formatter with `locale="es"`. Each case is a whole sentence;
`Intl.ListFormat` supplies "y".

<Canvas of={Stories.Translated} />

`format` gets `{ count, names, list }` and returns the whole sentence.
`names` is empty once `count` passes `maxNames`. Never build the sentence from
fragments like `name + " and " + other`: Russian and Polish have four plural
forms, Arabic six and Japanese one, and verb and word order change with them.
Write one sentence per case, for example as an ICU message:

```
{count, plural,
  =0 {}
  one {{list} is typing…}
  other {{list} are typing…}
}
```

plus a separate message for "Several people are typing…" when `names` is
empty. Pass the messages' `locale` so names are joined in that language.

## Usage

```tsx
import {
  TypingIndicator,
  type TypingPerson,
} from "@/components/ui/typing-indicator"

export function Channel({
  typing,
  me,
}: {
  typing: TypingPerson[]
  me: string
}) {
  return (
    <>
      <MessageList />
      <TypingIndicator people={typing} currentUserId={me} />
      <Composer />
    </>
  )
}
```

Pass everyone the typing events report, current user included; the component
omits them. Drop a person once their typing event expires (10 seconds on
Discord).
