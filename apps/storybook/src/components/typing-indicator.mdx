# Typing indicator

A typing indicator says who's writing a reply in a conversation. It names up
to three people, then says "Several people are typing…".

<Canvas of={Stories.Default} />

## Features

- Takes people as data and leaves out the person looking at the screen.
- One formatter builds the whole sentence, so it can be translated properly.
  Names are joined with `Intl.ListFormat` for the locale.
- Screen readers hear the sentence once it holds still for 1.5 seconds, and
  hear nothing when everyone stops.
- Keeps its height when nobody is typing, so the messages above don't jump.

## Usage

```tsx
import {
  TypingIndicator,
  type TypingPerson,
} from "@/components/ui/typing-indicator"

export function Channel({
  typing,
  me,
}: {
  typing: TypingPerson[]
  me: string
}) {
  return (
    <>
      <MessageList />
      <TypingIndicator people={typing} currentUserId={me} />
      <Composer />
    </>
  )
}
```

Pass everyone your typing events report, yourself included, and let the
component leave you out. Drop a person once their typing event expires, which
is 10 seconds on Discord.

## Examples

### One person

The verb agrees with the count.

<Canvas of={Stories.OnePerson} />

### Three people

Up to `maxNames` people are named, joined for the locale.

<Canvas of={Stories.Three} />

### Several people

Past `maxNames`, nobody is named. This is what Discord does from four people
on.

<Canvas of={Stories.Several} />

### Long names

Each name is cut short at `maxNameLength` characters, so one long name can't
push the others off the line. Screen readers still hear names in full.

<Canvas of={Stories.LongNames} />

### Custom indicator

A person's `indicator` replaces the dots while they're the only one typing.
With two or more people, everyone gets the dots again, as with Discord's
custom typing indicators.

<Canvas of={Stories.CustomIndicator} />

### Translated

A Spanish formatter with `locale="es"`. Each case is a whole sentence, and
`Intl.ListFormat` supplies "y".

<Canvas of={Stories.Translated} />

`format` gets `{ count, names, list }` and returns the whole sentence.
`names` is empty once `count` passes `maxNames`. Never build the sentence from
fragments like `name + " and " + other`: Russian and Polish have four plural
forms, Arabic six and Japanese one, and the verb and the word order change with
them. Write one sentence per case, as an ICU message for instance:

```
{count, plural,
  =0 {}
  one {{list} is typing…}
  other {{list} are typing…}
}
```

with a separate message for "Several people are typing…" when `names` is
empty. Pass the same `locale` the messages use, so the names are joined in that
language.

### In a conversation

People start and stop typing below a short thread. The row keeps its height,
so the messages stay put.
