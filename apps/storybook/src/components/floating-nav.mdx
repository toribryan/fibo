# Floating nav

A pill of destinations that floats above the bottom of a phone screen. The
current item stretches to show its name, and the bar can step out of the way
while people read.

<Canvas of={Stories.Default} />

## Features

- An indicator slides to the current item, which grows to show its label while
  the others stay as icons.
- Floats over the page, clear of the home indicator, or sits in the flow with
  `position="static"`.
- Can hide while the page scrolls down and return the moment it scrolls up or
  takes focus.
- Items are links or buttons, controlled or uncontrolled, so it works with any
  router.
- `variant="glass"` turns it into Apple's liquid glass: a clear bar that bends
  the page behind its edges, with a glass lens on the current item.

It is also how this site gets around on a phone: open fibo.toribryan.com on
one and the bar replaces Storybook's own.

## Examples

### Liquid glass

`variant="glass"` draws the bar as liquid glass. A lightly blurred, tinted
layer and a bright rim work in every browser. In Chromium the page behind the
rim also bends, through an SVG displacement filter sized to the bar; Safari and
Firefox keep the blur and rim. The current item sits under a glass lens that
overshoots a little as it lands, and the bar swells a touch under a finger.

Pressing the bar lifts the lens off it, the way iOS does as you change tabs:
it grows past the bar's edges, clears, and magnifies the item beneath with a
fringe of colour at its rim, then travels to the new item and settles back
into its tint. In Safari and Firefox it lifts and clears without the
magnifying. With reduced motion it stays put.

<Canvas of={Stories.Glass} />

### Labels always shown

`labels="always"` stacks every label under its icon, like a tab bar. Use it
when the icons alone would not say where they go.

<Canvas of={Stories.AlwaysLabelled} />

### Compact

`size="sm"` tightens the pill: 36px items and 16px icons instead of 44px and
20px. Use it where the bar should take less of the screen, such as a site that
also shows a scroll-to-top button or a chat launcher.

<Canvas of={Stories.Compact} />

### Text items

Leave out an item's `icon` and it shows its label as text, always. Use it when
there are only two or three places and their names say more than icons.

<Canvas of={Stories.TextItems} />

### Static

`position="static"` keeps the bar in the flow, for a toolbar at the foot of a
card or a preview like this one.

<Canvas of={Stories.Static} />

### Controlled links

Items with an `href` render as links. `onValueChange` hands over the click, so
an app can call `event.preventDefault()` and route it itself.

<Canvas of={Stories.ControlledLinks} />

## Usage

```tsx
import { BookmarkIcon, HouseIcon, UserIcon } from "lucide-react"

import { FloatingNav } from "@/components/ui/floating-nav"

const items = [
  { value: "home", label: "Home", icon: <HouseIcon />, href: "/" },
  { value: "saved", label: "Saved", icon: <BookmarkIcon />, href: "/saved" },
  { value: "profile", label: "Profile", icon: <UserIcon />, href: "/profile" },
]

export function AppNav({ pathname }: { pathname: string }) {
  return <FloatingNav items={items} value={pathname.split("/")[1] || "home"} />
}
```

Give every item a `label`, even with `labels="active"`. It is the item's name
for screen readers, and the label the current item shows.

Each item takes:

```ts
type FloatingNavItem = {
  value: string
  label: string
  icon?: React.ReactNode // leave out for a text item
  href?: string // renders a link; without it, a button
}
```

## Guidelines

<UsageGuidelines
  guidelines={[
    "Use it for the three to five places people move between most on a phone. Everything else belongs in a menu.",
    "Keep labels to one short word. The current label has to fit beside its icon on a 320px screen.",
    <>
