# Floating nav

A floating pill of destinations for phone screens that can hide on scroll.

<Canvas of={Stories.Default} />

## Features

- An indicator slides to the current item, which expands to show its label;
  the others stay as icons.
- Floats over the page, clear of the home indicator, or sits in the flow with
  `position="static"`.
- Can hide on scroll down and return on scroll up or focus.
- Items are links or buttons, controlled or uncontrolled, so it works with any
  router.
- `variant="glass"` renders Apple-style liquid glass: a clear bar that bends
  the page behind its edges, with a glass lens on the current item.

On a phone, fibo.toribryan.com uses it in place of Storybook's own navigation.

## Examples

### Liquid glass

A lightly frosted, tinted layer and a bright rim work in every browser. In
Chromium the page behind the rim also bends, through an SVG displacement
filter sized to the bar; Safari and Firefox keep the blur and rim. The
current item's lens overshoots slightly as it lands, and the bar swells
slightly under a finger.

A press lifts the lens, as iOS does when changing tabs: it grows past the
bar's edges, clears, and magnifies the item beneath with a color fringe at
its rim, then travels to the new item and settles back into its tint. Safari
and Firefox lift and clear without magnifying. Under reduced motion it stays
put.

The glass bar doesn't clip, so the lens can lift past it, and so it can't
scroll sideways like the default bar when items overflow. Keep glass bars to
items that fit, or use `size="sm"` on narrow screens.

<Canvas of={Stories.Glass} />

### Labels always shown

`labels="always"` stacks every label under its icon, like a tab bar. For
icons that are ambiguous alone.

<Canvas of={Stories.AlwaysLabeled} />

### Compact

`size="sm"`: 36px items and 16px icons instead of 44px and 20px. For screens
with other floating controls, such as a scroll-to-top button or chat
launcher.

<Canvas of={Stories.Compact} />

### Text items

An item without `icon` always shows its label as text. For two or three
places whose names say more than icons.

<Canvas of={Stories.TextItems} />

### Static

`position="static"` keeps the bar in the flow, for a toolbar at the foot of a
card or a preview.

<Canvas of={Stories.Static} />

### Controlled links

Items with an `href` render as links. `onValueChange` receives the click
event, so the app can call `event.preventDefault()` and route it.

<Canvas of={Stories.ControlledLinks} />

## Usage

```tsx
import { BookmarkIcon, HouseIcon, UserIcon } from "lucide-react"

import { FloatingNav } from "@/components/ui/floating-nav"

const items = [
  { value: "home", label: "Home", icon: <HouseIcon />, href: "/" },
  { value: "saved", label: "Saved", icon: <BookmarkIcon />, href: "/saved" },
  { value: "profile", label: "Profile", icon: <UserIcon />, href: "/profile" },
]

export function AppNav({ pathname }: { pathname: string }) {
  return <FloatingNav items={items} value={pathname.split("/")[1] || "home"} />
}
```

Every item needs a `label`, even with `labels="active"`. It names the item
for screen readers and is shown on the current item.

```ts
type FloatingNavItem = {
  value: string
  label: string
  icon?: React.ReactNode // leave out for a text item
  href?: string // renders a link; without it, a button
}
```
