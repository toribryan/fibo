# Switch

A switch turns a setting on or off, and the change takes effect straight
away, with no save button.

<Canvas of={Stories.Default} />

## Features

- On and off states, built on Base UI's Switch, announced as a switch.
- Two sizes: the default 32 by 18 pixel track, and a small one for dense rows.
- The hit area reaches past the track to meet the 24px minimum target.
- An invalid state through `aria-invalid` that keeps the focus ring.

<Install name="switch" exports={["Switch"]} />

## Usage

```tsx
import { Label } from "@/components/ui/label"
import { Switch } from "@/components/ui/switch"

export function WifiSetting() {
  return (
    <div className="flex items-center gap-2">
      <Switch id="wifi" defaultChecked />
      <Label htmlFor="wifi">Wi-Fi</Label>
    </div>
  )
}
```

Pass `checked` and `onCheckedChange` to control it, or `defaultChecked` to let
it keep its own state. Save the change as soon as it fires.

## API reference

Switch takes every prop of Base UI's `Switch.Root`, including `checked`,
`defaultChecked`, `onCheckedChange`, `name` and `value`.
