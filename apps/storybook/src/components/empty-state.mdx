# Empty state

A placeholder for missing content: a title, why it's empty, and what to do
next.

<Canvas of={Stories.Default} />

## Features

- Title, optional icon, description and actions, each a separate part.
- `size="sm"` for a line in a menu or popover, `default` for a table, list
  or page.
- Used by Data table when it has no rows (with Clear filters when a search or
  filter hid them) and by Message list before the first message.

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  EmptyState,
  EmptyStateActions,
  EmptyStateDescription,
  EmptyStateTitle,
} from "@/components/ui/empty-state"

export function NoMembers({ onInvite }: { onInvite: () => void }) {
  return (
    <EmptyState>
      <EmptyStateTitle>No members yet</EmptyStateTitle>
      <EmptyStateDescription>
        Invite people to work on this project with you.
      </EmptyStateDescription>
      <EmptyStateActions>
        <Button size="sm" onClick={onInvite}>
          Invite members
        </Button>
      </EmptyStateActions>
    </EmptyState>
  )
}
```

The title says what's missing, the action what to do. The description
explains why, only when it isn't obvious.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Name what's missing in the title: No members yet, not Nothing here.",
    "Distinguish first-run empty from no matches. One invites adding something, the other clearing a search.",
    "One primary action at most. A second is outline or ghost.",
    "Omit the icon in small empty states; menus have no room for it.",
  ]}
/>
