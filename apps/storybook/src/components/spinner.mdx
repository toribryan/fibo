# Spinner

A spinner is a ring that turns while something loads. It's on its way out:
new work should use an indeterminate Progress.

<Deprecation name="spinner" />

<Canvas of={Stories.Default} />

## Migration

The codemod above rewrites every Spinner in a project. Run it from the
project root, run your formatter and review the diff, then delete
`components/ui/spinner.tsx`.

```tsx
// Before
import { Spinner } from "@/components/ui/spinner"
;<Spinner size="sm" label="Loading comments" className="mx-auto" />

// After
import { Progress } from "@/components/ui/progress"
;<Progress value={null} aria-label="Loading comments" className="mx-auto" />
```

<Canvas of={Stories.Replacement} />

<UsageGuidelines
  guidelines={[
    <>
      The import moves to <code>progress</code>, keeping your alias, and joins
      an existing Progress import if there is one.
    </>,
    <>
      <code>label</code> becomes <code>aria-label</code>. With no label, the
      codemod writes <code>aria-label="Loading"</code>, the Spinner's default.
    </>,
    <>
      <code>size</code> is dropped. A progress bar fills its container, so set
      its width with <code>className</code> where it sits in a row.
    </>,
    "A Spinner passed around as a value, such as icon={Spinner}, is left alone and listed in the codemod's output to change by hand.",
    "Install Progress first if the project doesn't have it yet.",
  ]}
/>
