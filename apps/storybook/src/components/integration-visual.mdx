# Integration visual

A hub and the tools wired into it, on a plate. The hub takes an icon or
text, and defaults to a snail, for syncs that take their time. Pulses run along the routes of
the tools that are live, quiet ones sit back, and a preview springs up over
the hub on hover or focus. It explains a connection at a glance where a list
of logos would not.

## Usage

<UsageGuidelines
  guidelines={[
    <>
      Choose the layout by count: <code>corners</code> for four,{" "}
      <code>orbit</code> for five to eight, <code>sides</code> when data flows

    </>,
    <>

    </>,

  ]}

<Tip>
  The preview is for looking at, not for acting in: nothing inside it can be
  clicked. Link out from the card around the diagram instead. It opens above the
  hub, so leave it off when the plate is small or sits in a card that would clip
  it.
</Tip>

## Variants

### Media preview

`preview` takes `{ src, alt }` as well as any content: an image, an animated
image, or a video that plays muted on a loop. Media is 16:9 by default; pass
`aspectRatio` for other shapes. Hover or focus the snail.

<Canvas of={Stories.MediaPreview} />

### Orbit

Any count up to eight, evenly spaced on an ellipse with straight spokes.

<Canvas of={Stories.Orbit} />

### Sides

A pipeline: inputs on the left, outputs on the right, each route bending
through a shared bus. Set `side` on an item to choose its column.
