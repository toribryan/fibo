# Integration visual

A hub and the tools wired into it. Live routes pulse, idle ones dim, and the
hub opens a preview on hover.

<Canvas of={Stories.Default} />

## Features

- Three layouts: `corners` for up to four tools, `orbit` for up to eight, and
  `sides` for a pipeline with inputs on one side and outputs on the other.
- Pulses run inward, outward, or through the hub from left to right along
  live routes. Idle tools keep their route and dim.
- A preview opens over the hub on hover or focus. It takes any content, or an
  image or looping video, and it's a Base UI tooltip: portalled so no card
  clips it, hoverable, and dismissed with Escape.
- Respects reduced motion: the pulses, halo and springs stop, the preview
  fades in, and a preview video waits on its first frame.

## Installation

<Install
  name="integration-visual"
  exports={["IntegrationVisual", "type IntegrationItem"]}
/>

It installs `motion` with it, for the pulses and the halo.

## Usage

```tsx
import { DatabaseIcon, MailIcon } from "lucide-react"

import { IntegrationVisual } from "@/components/ui/integration-visual"

export function ConnectedTools() {
  return (
    <IntegrationVisual
      label="Connected tools"
      items={[
        { title: "Database", icon: <DatabaseIcon /> },
        { title: "Email", icon: <MailIcon />, status: "idle" },
      ]}
    />
  )
}
```

Items fill the layout's slots in order, and any past its limit are left out.
Each `title` names its tile for screen readers.

Each item takes:

```ts
type IntegrationItem = {
  title: string
  icon: React.ReactNode
  status?: "active" | "idle"
  side?: "in" | "out" // sides layout only
}
```

## Guidelines

<UsageGuidelines
  guidelines={[
    <>
      Choose the layout by count: <code>corners</code> for four,{" "}
      <code>orbit</code> for five to eight, <code>sides</code> when data flows
      in one side and out the other.
    </>,
    <>
      Mark tools that aren't connected yet as <code>idle</code> rather than
      leaving them out. The diagram then shows what's possible as well as what's
      live.
    </>,
    <>
      Use <code>pulse="inward"</code> for sources feeding the hub,{" "}
      <code>"outward"</code> for the hub sending to them, and{" "}
      <code>"through"</code> for a pipeline that flows from left to right.
    </>,
    <>
      Name the hub with the product, a count, or a mark in <code>center</code>.
      Keep it to a word or a number.
    </>,
    "Put it at the top of a card and let the card's text make the claim.",
  ]}
/>

<Tip>
  The preview is for looking at: keyboard users can't reach anything inside it,
  so link out from the card around the diagram instead.
</Tip>

## Examples

### Media preview

Pass `{ src, alt }` to `preview` for an image, an animated image, or a video
that plays muted on a loop. Media is 16:9 unless you set `aspectRatio`. Hover
or focus the snail.

<Canvas of={Stories.MediaPreview} />

### Orbit

Up to eight tools, evenly spaced on an ellipse with straight spokes.

<Canvas of={Stories.Orbit} />

### Sides

A pipeline. Set `side` on each item to put it in the input or output column,
and `pulse="through"` to run the pulses from inputs, through the hub, to
outputs.

<Canvas of={Stories.Sides} />

### Idle items

Every other tool is `idle`: its route stays, dimmed, and carries no pulse.

<Canvas of={Stories.IdleItems} />

### Plates

The `background` prop sets the plate: `dots`, `grid` or `none`.

<Canvas of={Stories.Plates} />

### In a card

A count in the hub and the claim in the card text below it.

<Canvas of={Stories.InACard} />
