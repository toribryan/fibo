# Slider

A slider picks a number, or a range between two, by dragging a thumb along a
track. It suits values where roughly right is right enough.

<Canvas of={Stories.Default} />

## Features

- One thumb for a value, or two for a range, built on Base UI's Slider.
- Arrow keys step the value; Page Up and Page Down take bigger steps; Home
  and End jump to the ends.
- Horizontal or vertical, with a `step` to snap to.
- The thumb lines up with the track's ends at the minimum and maximum
  instead of hanging over them.

## Usage

```tsx
import { Slider } from "@/components/ui/slider"

export function Volume() {
  return <Slider defaultValue={[40]} aria-label="Volume" />
}
```

Every thumb needs a name. For one thumb, `aria-label` on the Slider is passed
to it. For a range, name each one with `thumbLabels`:

```tsx
<Slider
  defaultValue={[20, 80]}
  thumbLabels={["Minimum price", "Maximum price"]}
/>
```

## API reference

Slider takes every prop of Base UI's `Slider.Root`, including `value`,
`defaultValue`, `onValueChange`, `onValueCommitted`, `min`, `max`, `step`,
`largeStep` and `orientation`.
