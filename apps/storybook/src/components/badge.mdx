# Badge

A short, non-interactive label for a status, category or count, placed next
to what it describes.

<Canvas of={Stories.Default} />

## Features

- Three neutral variants, `default`, `secondary` and `outline`, and four
  status tints: `destructive` for states that need action, `success`,
  `warning` and `info`.
- Sized for one or two words.
- Not in the tab order.

## Usage

```tsx
import { Badge } from "@/components/ui/badge"

export function InvoiceStatus() {
  return (
    <div className="flex items-center gap-2">
      Invoice #1042 <Badge variant="destructive">Overdue</Badge>
    </div>
  )
}
```

Say the state in the label. The variant only reinforces it.

## Guidelines

<UsageGuidelines
  guidelines={[
    "One or two words, readable at a glance.",
    "Use default for the one state that needs attention, secondary or outline for everything else.",
    "Use destructive only for states that need action, such as Failed or Overdue.",
    "Use success, warning and info only for a status with that meaning, such as Paid, Expiring or Beta, never for decoration.",
    "If it should respond to a click, use a Button.",
  ]}

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <div className="flex items-center gap-2 text-sm">
            Invoice #1042 <Badge variant="destructive">Overdue</Badge>
          </div>
        ),
        description: "Say the state in the label, and let color reinforce it.",
      },
      negative: {
        component: (
          <div className="flex items-center gap-2 text-sm">
            Invoice #1042{" "}
            <Badge variant="destructive">
              This invoice is now 14 days overdue
            </Badge>
          </div>
        ),
        description:
          "Don't write a sentence. Move longer copy into the row itself.",
      },
    },
  ]}
/>
