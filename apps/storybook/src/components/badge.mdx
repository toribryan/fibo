# Badge

A badge is a short, non-interactive label for a status, category or count. It
sits next to the thing it describes.

<Canvas of={Stories.Default} />

## Features

- Three neutral variants, `default`, `secondary` and `outline`, and four
  status tints: `destructive` for states that need action, `success`,
  `warning` and `info`.
- Sized for one or two words, next to the thing it describes.
- Not interactive, so it adds nothing to the tab order.

## Usage

```tsx
import { Badge } from "@/components/ui/badge"

export function InvoiceStatus() {
  return (
    <div className="flex items-center gap-2">
      Invoice #1042 <Badge variant="destructive">Overdue</Badge>
    </div>
  )
}
```

Say the state in the label. The variant only reinforces it.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Keep it to one or two words, so it can be taken in at a glance.",
    "Use default for the one state that needs attention, secondary or outline for everything else.",
    "Use destructive only for states that need action, such as Failed or Overdue.",
    "Use success, warning and info for a status that has one of those meanings, such as Paid, Expiring or Beta. Never for decoration.",
    "If clicking it should do something, use a Button instead.",
  ]}
/>

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <div className="flex items-center gap-2 text-sm">
            Invoice #1042 <Badge variant="destructive">Overdue</Badge>
          </div>
        ),
        description: "Say the state in the label, and let colour reinforce it.",
      },
      negative: {
        component: (
          <div className="flex items-center gap-2 text-sm">
            Invoice #1042{" "}
            <Badge variant="destructive">
              This invoice is now 14 days overdue
            </Badge>
          </div>
        ),
        description:
          "Don't write a sentence. Move longer copy into the row itself.",
      },
    },
  ]}
/>
