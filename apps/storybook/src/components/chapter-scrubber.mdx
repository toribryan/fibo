# Chapter scrubber

A rail of chapter marks that swell around the pointer, Dock-style, with the
tallest mark (the crest) previewing its chapter.

<Canvas of={Stories.Default} />

## Features

- Marks swell around the pointer or keyboard focus. The crest previews its
  chapter as a card, a label, or nothing.
- Vertical or horizontal, ticks or dots, three densities.
- Controlled or uncontrolled, so the marker can follow scroll or playback.
- Under reduced motion the springs switch off; the wave keeps its shape but
  appears and follows instantly.

## Installation

<Install

## Usage

```tsx
import { ChapterScrubber } from "@/components/ui/chapter-scrubber"

const chapters = [
  { id: "intro", title: "Introduction" },
  { id: "tokens", title: "Token tiers", description: "Ramps, then roles." },
  { id: "figma", title: "Figma variables", meta: "12:40" },
]

export function Contents() {
  return <ChapterScrubber chapters={chapters} />
}
```

One mark per chapter, in array order. `title` and `description` name each
mark for screen readers.

```ts
type Chapter = {
  id: string
  title: string
  description?: React.ReactNode // clamped to three lines
  meta?: React.ReactNode // a small label beside the title, such as a timestamp
}
```

## Guidelines

<UsageGuidelines
  guidelines={[
    "Use for sequential content: a talk, a long read, a case study, a recording.",
    "Keep six to thirty chapters. Fewer reads as a list; more stops the wave reaching neighbors.",
    <>
      Use <code>card</code> when chapters have descriptions, <code>label</code>{" "}

    <>

      scrolls out of view.

### Data attributes

Style parts by slot or state, e.g.
`[&_[data-slot=chapter-scrubber-item]]:rounded-none`. The preview is portalled
to the body, outside the rail's selectors; style it with `previewClassName`,
e.g. `previewClassName="shadow-none"`.
