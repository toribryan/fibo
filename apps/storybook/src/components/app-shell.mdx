# App shell

The frame of a workspace app: a header with Command menu, the current page,
and Floating nav to move between pages. Press Cmd+K or Ctrl+K in the preview
to create a project, open one from a nested page, or clear the inbox.

<BlockPreview label="App shell">
  {(container) => <AppShell container={container} className="min-h-full" />}
</BlockPreview>

## Features

- **Commands that do things.** New project adds a row and opens Projects,
  Open project is a nested page of every project, and Mark all as read
  empties the inbox. Each runs through the same setters the pages use.
- **Recents.** The commands you run float to the top of the menu, as
  Command menu does on its own.
- **Lays out by its own width.** Container queries on the root, not the
  viewport, so the shell reads the same full screen, in a split view or in
  this preview. At phone width the cards stack and the table drops its
  Owner and Updated columns.
- **Stays in its container.** The header and nav are sticky rather than
  fixed, so the shell can sit inside another layout without escaping it.

## Installation

<Install name="app-shell" block exports={["AppShell"]} />

Then render it where the screen goes:

```tsx
import { AppShell } from "@/components/blocks/app-shell/app-shell"

export default function Page() {
  return <AppShell />
}
```

A block is installed once and then belongs to your app. Running `shadcn add`
again overwrites your edits, so change the files instead.

## Files

| File            | Holds                                                             |
| --------------- | ----------------------------------------------------------------- |
| `app-shell.tsx` | The header, Command menu's commands, page state and Floating nav. |
| `pages.tsx`     | Home, Projects and Inbox.                                         |
| `data.ts`       | The workspace, user, projects and messages, with their types.     |

## Make it yours

1. Replace `data.ts` with your own data, or load it where `AppShell` reads
   it. The pages only read the types.
2. Swap the `page` state for your router: give each nav item an `href`, and
   call `event.preventDefault()` in `onValueChange` if the router handles
   links itself.
3. Add commands to `groups` in `app-shell.tsx`. A command with `items` opens
   a page of its own.
