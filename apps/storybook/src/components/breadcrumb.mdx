# Breadcrumb

Shows where a page sits in the app. A segment can open a menu to switch to a
sibling, such as another database, without going back up the trail.

<Canvas of={Stories.Default} />

## Features

- A trail of links ending on the current page, marked `aria-current="page"`.
- `BreadcrumbMenuTrigger` turns a segment into a Menu trigger, with an
  optional icon and an up-down chevron.
- `BreadcrumbLink` takes `render`, so a router's link keeps the styles.
- Any separator, and an ellipsis for collapsed levels.

## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbMenuTrigger,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb"
import {
  Menu,
  MenuContent,
  MenuRadioGroup,
  MenuRadioItem,
} from "@/components/ui/menu"

export function DatabaseTrail({ database, databases, onSwitch }: Props) {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/databases">Databases</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <Menu>
            <BreadcrumbMenuTrigger icon={<DatabaseIcon />}>
              {database}
            </BreadcrumbMenuTrigger>
            <MenuContent>
              <MenuRadioGroup value={database} onValueChange={onSwitch}>
                {databases.map((name) => (
                  <MenuRadioItem key={name} value={name} closeOnClick>
                    {name}
                  </MenuRadioItem>
                ))}
              </MenuRadioGroup>
            </MenuContent>
          </Menu>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  )
}
```

The menu trigger shows the current choice as its label, so the trail still
reads as a path.
