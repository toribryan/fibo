# Avatar

An avatar shows who someone is: their photo, or their initials when there's
no photo or it fails to load.

<Canvas of={Stories.Default} />

## Features

- Falls back to initials until the photo loads, and stays on them if it
  never does, built on Base UI's Avatar.
- Three sizes: 24, 32 and 40 pixels.
- A badge in the corner for status, such as online.
- Groups overlap into a stack, with a count for the people left out.

## Installation

<Install name="avatar" exports={["Avatar", "AvatarImage", "AvatarFallback"]} />

`AvatarBadge`, `AvatarGroup` and `AvatarGroupCount` are exported too.

### With status

Put a [Status dot](?path=/docs/base-components-display-status-dot--docs) in the

label is read after the photo's `alt`.

<Canvas of={Stories.WithStatus} />

### With badge

AvatarBadge puts a small badge in the corner for anything that isn't
presence, such as an icon. Name it in the photo's `alt`.

<Canvas of={Stories.WithBadge} />

### Group

AvatarGroup overlaps the avatars; AvatarGroupCount says how many more. Put a
[Count](?path=/docs/base-components-display-count--docs) with `plus` in it,
so it shows +4 and reads “4 more”.

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"

export function Author() {
  return (
    <Avatar>
      <AvatarImage src="/people/ada.jpg" alt="Ada Lovelace" />
      <AvatarFallback>AL</AvatarFallback>
    </Avatar>
  )
}
```

Always include an AvatarFallback. It shows while the photo loads and stays if
the photo fails.

      },
    },
  ]}

## API reference

Avatar takes every prop of Base UI's `Avatar.Root`. AvatarImage takes
`src`, `alt` and `onLoadingStatusChange`; AvatarFallback takes `delay` to
wait before showing, so a fast photo doesn't flash the initials first.
