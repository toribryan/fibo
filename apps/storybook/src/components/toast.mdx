# Toast

A toast is a brief message in the corner of the screen about something that
just happened, such as a save or a failed upload. It leaves on its own.

<Canvas of={Stories.Default} />

## Features

- Built on Base UI's Toast: queue a toast from anywhere, even outside React,
  with `toast.add()`.
- Toasts stack in the bottom corner and fan out on hover or focus.
- Success, info, warning and error types, each with its own icon, plus a
  loading state that follows a promise.
- An optional action, such as Undo, and swipe to dismiss.

## Usage

Mount the Toaster once, near the root of your app:

```tsx
import { Toaster } from "@/components/ui/toast"

export function App({ children }: { children: React.ReactNode }) {
  return <Toaster>{children}</Toaster>
}
```

Then add toasts from anywhere:

```tsx
import { toast } from "@/components/ui/toast"

toast.add({
  title: "Changes saved",
  description: "Your profile is up to date.",
})
```

`toast.add` returns an id you can pass to `toast.close` or `toast.update`.

## Guidelines

## API reference

Toaster takes Base UI's `Toast.Provider` props, including `timeout` (5000
ms by default, 0 to keep toasts until dismissed) and `limit` (3). `toast.add`
takes `title`, `description`, `type`, `timeout`, `priority` and
`actionProps`.
