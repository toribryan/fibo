# Field

Puts a label, a description and an error round one form control and wires
them to it, so nothing needs an `id`. FieldGroup sets the size of every
control in a form at once.

<Canvas of={Stories.Default} />

## Features

- Names the control from `FieldLabel` and describes it with
  `FieldDescription`, through Base UI's Field, for Input, Textarea, Select,
  Checkbox, Radio group, Switch and Slider.
- `invalid` turns the control's border destructive and shows `FieldError`;
  `disabled` disables the control and dims its label.
- `orientation="horizontal"` lays a checkbox or switch beside its label, and
  `FieldItem` does the same for each option in a radio group.
- `FieldGroup size="sm"` makes every Input, Select and Switch inside it
  small; a field's or control's own `size` still wins.

## Usage

```tsx
import {
  Field,
  FieldDescription,
  FieldError,
  FieldLabel,
} from "@/components/ui/field"
import { Input } from "@/components/ui/input"

export function EmailField({ error }: { error?: string }) {
  return (
    <Field invalid={Boolean(error)}>
      <FieldLabel>Work email</FieldLabel>
      <Input type="email" />
      <FieldDescription>We send receipts here.</FieldDescription>
      <FieldError>{error}</FieldError>
    </Field>
  )
}
```

One control per Field. For a group of options, put the Radio group in the
Field and each option in a `FieldItem`.
