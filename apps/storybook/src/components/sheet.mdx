# Sheet

Sheet slides a panel in from an edge of the screen for a focused task, such
as editing a record or setting filters on a phone, without leaving the page.

<Canvas of={Stories.Default} />

## Features

- Slides in from any edge, and can be swiped back the way it came.
- A modal dialog: focus moves in and stays in, the page behind can't scroll,
  and focus returns to the trigger on close.
- Closes on Escape, a click outside, or the close button.
- Text in SheetBody can be selected without dragging the sheet.

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Sheet,
  SheetBody,
  SheetContent,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet"

export function Filters() {
  return (
    <Sheet side="bottom">
      <SheetTrigger render={<Button variant="outline" />}>Filters</SheetTrigger>
      <SheetContent>
        <SheetHeader>
          <SheetTitle>Filters</SheetTitle>
        </SheetHeader>
        <SheetBody>{/* Sort, group and filter controls */}</SheetBody>
      </SheetContent>
    </Sheet>
  )
}
```

`side` goes on Sheet, not on SheetContent as in shadcn's Sheet, because it
also sets which way the sheet is swiped to close. Always give it a SheetTitle.

## API reference

Sheet takes Base UI's Drawer Root props, with `side` in place of
`swipeDirection`. SheetContent takes the Popup's props plus
`showCloseButton`, and the other parts take the props of the Base UI part or
element they wrap.
