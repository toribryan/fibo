# Voice memo

A voice recorder modelled on the clip-on memo devices that stick to the back
of a phone: an aluminium recorder docked on the edge, a running clock, a
waveform that glides in from the right as you talk, and controls to mark a
moment, pause and stop.

<Canvas of={Stories.Default} />

## Features

- A brushed aluminium device, docked against the left edge. Its pinhole
  glows with your voice while recording. Hover and it lifts; click it to
  record or pause; pull it out and let go, and it snaps back as if a magnet
  caught it.
- A waveform that glides in from the right and fades off the left into the
  device, with silence drawn as dots so pauses in speech show as gaps.
- Mark a moment while you talk. The mark lands as a tick on the bar it was
  made over and scrolls away with it, and `onStop` hands back every mark's
  time.
- A clock to the hundredth of a second that leaves pauses out, with a
  recording light: red while recording, amber while paused.
- An optional status line for the device: connected, connecting or
  disconnected, and its battery.
- Draws in fibo's tokens, so the aluminium is silver in the light theme and
  space grey in the dark.

## Usage

The component draws and times a take; your code does the recording. Start a
`MediaRecorder` when the state turns to `recording`, and pass its stream in
so the waveform follows the voice:

```tsx
import { useRef, useState } from "react"

import { VoiceMemo } from "@/components/ui/voice-memo"

export function Recorder() {
  const [stream, setStream] = useState<MediaStream | null>(null)
  const recorder = useRef<MediaRecorder | null>(null)

  return (
    <VoiceMemo
      stream={stream}
      simulate={false}
      onStateChange={async (state) => {
        if (state === "recording" && !recorder.current) {
          const media = await navigator.mediaDevices.getUserMedia({
            audio: true,
          })
          recorder.current = new MediaRecorder(media)
          recorder.current.start()
          setStream(media)
        }
        if (state === "paused") recorder.current?.pause()
        if (state === "recording") recorder.current?.resume()
      }}
      onStop={({ duration, marks }) => {
        recorder.current?.stop()
        recorder.current = null
        setStream(null)
      }}
    />
  )
}
```

`onStop` receives `{ duration: number; marks: number[] }`, both in
milliseconds. Set `simulate={false}` in production: it's on by default so a
preview has a voice to draw before anything is wired up.
