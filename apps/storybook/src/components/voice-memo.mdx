# Voice memo

An aluminium recorder, after the clip-on memo devices that hold to the
back of a phone, that writes down what you say. Press it and a transcript
opens beside it, filling in as you talk; press it again and the transcript
stays, ready to copy or download as a Markdown file.

<Canvas of={Stories.Default} />

## Features

- One button. The device itself starts and stops listening, and its
  pinhole glows red while it does.
- A live transcript beside the device: settled words in full, the words
  still being worked out fainter after them. It follows the newest words
  unless you scroll up to reread.
- Saves the transcript as a `.md` file: the title, when it was said and for
  how long, then a paragraph per phrase led by its timestamp.
- Uses the browser's own speech recognition, with nothing to install, or
  shows text from your own service through `transcript` and `interim`.
- Tidies what the browser hears: fillers and doubled words dropped, "I" and
  each sentence capitalised, a full stop or question mark at the end.
- Aluminium drawn in fibo's tokens, silver in the light theme and space
  grey in the dark, that lifts on hover and presses in on a click.

## Usage

With no props it transcribes through the browser. Once stopped, the
transcript offers a download as a `.md` file, and `onComplete` hands back the
text and the memo, Markdown included, for saving it yourself:

```tsx
import { VoiceMemo } from "@/components/ui/voice-memo"

export function Notes() {
  return (
    <VoiceMemo
      title="Standup"
      onComplete={(text, memo) => saveNote(memo.filename, memo.markdown)}
    />
  )
}
```

The memo is a `VoiceMemoResult`:

```ts
type VoiceMemoResult = {
  title: string
  transcript: string
  segments: { at?: number; text: string }[] // at: ms from the start
  startedAt: Date
  duration: number // ms
  markdown: string
  filename: string // standup-2026-10-02-1405.md
}
```

The file reads like this:

```md
# Standup

October 2, 2026 at 2:05 PM · 00:42 · 61 words

**00:01** Quick note for the design review.

**00:04** The token drift check passes in both themes.
```

With your own speech-to-text service, pass what it has settled as
`transcript` and what it's still guessing as `interim`. The browser's
recogniser stays off:

```tsx
<VoiceMemo
  recording={recording}
  onRecordingChange={setRecording}
  transcript={final}
  interim={partial}
/>
```

Text from your own service is shown as you pass it. To give it the same
light grammar as the browser's, run each settled phrase through
`tidyPhrase` first.

Browser recognition works in Chrome, Edge and Safari, and sends audio to the
browser maker's servers to transcribe. Where it isn't available, or for
speech that must stay on your own servers, bring your own service.
