# Voice memo

An aluminum recorder, modeled on clip-on phone memo devices, that
transcribes speech into a transcript to copy or download as Markdown.

<Canvas of={Stories.Default} />

## Features

- One button. The first press wakes the device with a hop and a shake, and
  the pinhole glows green. Later presses start and stop listening, the
  pinhole pulsing red meanwhile. `defaultAwake` skips the wake step.
- A live transcript beside the device: settled words in full, interim words
  fainter after them. It follows the newest words unless scrolled up.
- Saves the transcript as a `.md` file: title, start time and duration, then
  a paragraph per phrase led by its timestamp.
- Uses the browser's speech recognition, or shows text from another service
  through `transcript` and `interim`.
- Tidies browser output: fillers and doubled words dropped, "I" and each
  sentence capitalized, a period or question mark at the end.
- Aluminum drawn in fibo's tokens: silver in light, space gray in dark, or
  burgundy in both. Lifts on hover and presses in on click.

## Usage

With no props it transcribes through the browser. Once stopped, the
transcript offers a `.md` download, and `onComplete` returns the text and the
memo, Markdown included:

```tsx
import { VoiceMemo } from "@/components/ui/voice-memo"

export function Notes() {
  return (
    <VoiceMemo
      title="Standup"
      onComplete={(text, memo) => saveNote(memo.filename, memo.markdown)}
    />
  )
}
```

The memo is a `VoiceMemoResult`:

```ts
type VoiceMemoResult = {
  title: string
  transcript: string
  segments: { at?: number; text: string }[] // at: ms from the start
  startedAt: Date
  duration: number // ms
  markdown: string
  filename: string // standup-2026-10-02-1405.md
}
```

The file:

```md
# Standup

October 2, 2026 at 2:05 PM · 00:42 · 61 words

**00:01** Quick note for the design review.

**00:04** The token drift check passes in both themes.
```

For an external speech-to-text service, pass settled text as `transcript`
and interim guesses as `interim`. The browser's recognizer stays off:

```tsx
<VoiceMemo
  recording={recording}
  onRecordingChange={setRecording}
  transcript={final}
  interim={partial}
/>
```

External text is shown as passed. Run each settled phrase through
`tidyPhrase` for the same cleanup as browser text.

Browser recognition works in Chrome, Edge and Safari, and sends audio to the
browser maker's servers. Where it's unavailable, or audio must stay on your
servers, use an external service.
