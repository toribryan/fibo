# Rich text editor

A Tiptap-based editor for formatted writing (headings, emphasis, lists,
quotes and links), with a toolbar and Markdown shortcuts.

<Canvas of={Stories.Default} />

## Features

- Bold, italic, strikethrough, inline code, a heading, lists, quotes and links
  from the toolbar, a shortcut, or Markdown as you type (`## `, `- `, `1. `,
  `> `, backticks).
- The toolbar is one tab stop; arrows, Home and End move inside it, and each
  button reports whether it's on.
- Links are entered in a row under the toolbar, not a browser prompt. An
  address Link refuses, such as `javascript:`, stays in the row marked
  invalid and never reaches the document.
- `maxLength` stops typing and pasting at the limit and counts down from 80%.

## Usage

```tsx
import { Label } from "@/components/ui/label"
import {
  RichTextEditor,
  type RichTextEditorTool,
} from "@/components/ui/rich-text-editor"

// "heading" | "bold" | "italic" | "strike" | "code" | "bullet" | "ordered"
// | "quote" | "link" | "history"
const tools: RichTextEditorTool[] = [
  "heading",
  "bold",
  "italic",
  "bullet",
  "link",
  "history",
]

export function ReleaseNote({ onSave }: { onSave: (html: string) => void }) {
  return (
    <div className="flex flex-col gap-2">
      <Label id="release-note-label">Release note</Label>
      <RichTextEditor
        aria-labelledby="release-note-label"
        defaultValue="<p>What changed, and who it affects.</p>"
        tools={tools}
        maxLength={2000}
        onChange={(html) => onSave(html)}
      />
    </div>
  )
}
```

The writing area isn't a form control, so a label's `for` can't target it.
Name it with `aria-labelledby` and the label's `id`. With Field, give
`FieldLabel` an `id`, and `FieldDescription` one for `aria-describedby`.
`id`, `aria-labelledby`, `aria-describedby` and `aria-invalid` go on the
writing area, not the frame.

The editor owns the document once mounted: `defaultValue` seeds it and
`onChange` reports changes. To clear or replace it, change its `key` or use
the Tiptap editor `onChange` passes. Sanitize the HTML on the server before
showing it to anyone else.
