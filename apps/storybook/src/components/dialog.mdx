# Dialog

A modal window over the page for a short task, such as editing a few fields.

<Canvas of={Stories.Default} />

## Features

- Modal, with focus trapping and scroll lock. See Accessibility.
- Closes on Escape, an outside click, the corner button or any DialogClose.
- Three widths. DialogBody scrolls when content exceeds the viewport, keeping
  the footer in reach.
- Fades and scales in from 95%, like Command menu. Appears in place under
  reduced motion.

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog"

export function EditProfile() {
  return (
    <Dialog>
      <DialogTrigger render={<Button variant="outline" />}>
        Edit profile
      </DialogTrigger>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Edit profile</DialogTitle>
          <DialogDescription>
            Changes show on your profile once you save.
          </DialogDescription>
        </DialogHeader>
        {/* Fields */}
        <DialogFooter>
          <DialogClose render={<Button variant="outline" />}>
            Cancel
          </DialogClose>
          <DialogClose render={<Button />}>Save changes</DialogClose>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}
```

DialogTitle is required; it names the dialog for screen readers. For an
irreversible confirmation, use Alert dialog.

## API reference

Dialog takes Base UI Dialog Root props (`open`, `defaultOpen`,
`onOpenChange`). DialogContent takes Popup props plus `size`,
`showCloseButton` and `container`. Other parts take the props of the Base UI
part or element they wrap.
