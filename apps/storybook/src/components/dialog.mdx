# Dialog

Dialog opens a window over the page for a short task, such as editing a few
fields, and keeps focus there until it's done or dismissed.

<Canvas of={Stories.Default} />

## Features

- A modal dialog: focus moves in and stays in, the page behind can't scroll,
  and focus returns to the trigger on close.
- Closes on Escape, a click outside, the corner button or any DialogClose.
- Three widths, and a DialogBody that scrolls when the content is taller
  than the screen, so the footer stays in reach.
- Fades and scales in from 95%, as Command menu does, and appears in place
  with reduced motion.

## Usage

```tsx
import { Button } from "@/components/ui/button"
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog"

export function EditProfile() {
  return (
    <Dialog>
      <DialogTrigger render={<Button variant="outline" />}>
        Edit profile
      </DialogTrigger>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Edit profile</DialogTitle>
          <DialogDescription>
            Changes show on your profile once you save.
          </DialogDescription>
        </DialogHeader>
        {/* Fields */}
        <DialogFooter>
          <DialogClose render={<Button variant="outline" />}>
            Cancel
          </DialogClose>
          <DialogClose render={<Button />}>Save changes</DialogClose>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}
```

Always give it a DialogTitle: it names the dialog for screen readers. For a
question with no way back, use Alert dialog instead.

## API reference

Dialog takes Base UI's Dialog Root props, such as `open`, `defaultOpen` and
`onOpenChange`. DialogContent takes the Popup's props plus `size`,
`showCloseButton` and `container`, and the other parts take the props of the
Base UI part or element they wrap.
