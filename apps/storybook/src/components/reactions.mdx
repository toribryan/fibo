# Reactions

Reactions let people respond to content with an emoji in one tap. They sit
inline under the content or float in a corner of the page.

<Canvas of={Stories.InMessage} />

## Features

- Inline pills under the content, or a floating bar pinned to a corner of the
  viewport.
- One tap to react or take it back, with a particle burst. Counts past a
  thousand shorten to 1.2K.
- A picker of six common reactions, plus any already on the item. It's a
  Base UI popover, so a card that clips its overflow can't cut it off, and it
  flips to whichever side has room.
- Controlled or uncontrolled. Particles and pill motion switch off under
  reduced motion.

## Installation

<Install name="reactions" exports={["Reactions", "type Reaction"]} />

No animation library: the burst and the pill motion use the Web Animations API.

## Usage

```tsx
import { Reactions } from "@/components/ui/reactions"

export function MessageReactions() {
  return (
    <Reactions
      defaultReactions={[
        { emoji: "👍", label: "Thumbs up", count: 5 },
        { emoji: "❤️", label: "Heart", count: 3, active: true },
      ]}
    />
  )
}
```

A reaction's `emoji` is its identity, so keep it unique. Its `label` is what
screen readers hear.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Use inline beside the content it belongs to, such as a message, comment or post.",
    "Use floating for a page-level reaction, such as the end of an article. It pins to a viewport corner.",
    "Offer five or six choices at most. More turns a quick tap into a decision.",
    <>
      Leave <code>choices</code> unset to get six common reactions. Anything
      already on the item is added to them.
    </>,
    "A reaction nobody holds any more disappears instead of lingering as a zero.",
    "Counts past a thousand shorten to 1.2K, so a busy post keeps its pills small.",
  ]}
/>

<Tip>
  Pass <code>reactions</code> and <code>onReactionsChange</code> to control the
  state from your data layer. Without them the component keeps its own state,
  seeded from <code>defaultReactions</code>.
</Tip>

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {

              { emoji: "❤️", label: "Heart", count: 3, active: true },
            ]}
          />
        ),
        description: "Keep reactions right under the content they respond to.",
      },
      negative: {
        component: (
          <Reactions
            particles={0}
            defaultReactions={[
              "👍",
              "❤️",
              "😂",
              "🎉",
              "😮",
              "🔥",
              "👀",
              "🙌",
              "💯",
            ].map((emoji, i) => ({ emoji, label: emoji, count: 9 - i }))}
          />
        ),
        description:
          "Don't let every emoji become a pill. A wall of reactions reads as noise; offer fewer choices.",
      },
    },
  ]}
/>
