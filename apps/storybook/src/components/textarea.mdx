# Textarea

A textarea takes several lines of free text. It grows with its content through
`field-sizing: content`, so it never needs its own scrollbar.

<Canvas of={Stories.Default} />

## Features

- Grows with its content through `field-sizing: content`, so it never needs its
  own scrollbar.
- Starts at a 64px minimum height. Set a taller one through `className`.
- Takes every native `textarea` prop, with the same invalid state as Input.

## Usage

```tsx
import { Label } from "@/components/ui/label"
import { Textarea } from "@/components/ui/textarea"

export function Notes() {
  return (
    <div className="flex flex-col gap-2">
      <Label htmlFor="notes">Notes</Label>
      <Textarea id="notes" placeholder="Anything we should know?" />
    </div>
  )
}
```

Pair it with a visible Label, and state any length limit before people reach
it.
