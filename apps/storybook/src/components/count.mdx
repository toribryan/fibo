# Count

A number as people take it in at a glance: capped at 99+, shortened to 1.2K,
or signed as +4. Screen readers hear the exact number, or your words.

<Canvas of={Stories.Default} />

## Features

- Caps with `max`, shortens with `notation="compact"`, and signs a count of
  things not shown with `plus`.
- Figures don't shift as the number changes.
- Says the exact number when the one shown is capped or shortened, or a
  label you write, such as “128 unread”.
- Text only: the part it sits in sets its size, weight and colour.

## Usage

```tsx
import { Badge } from "@/components/ui/badge"
import { Count } from "@/components/ui/count"

export function Unread({ count }: { count: number }) {
  return (
    <Badge variant="secondary">
      <Count value={count} max={99} label={(n) => `${n} unread`} />
    </Badge>
  )
}
```

When the count is part of a sentence, such as “12 new messages”, use
`formatCount` and write the sentence yourself, so it can be translated whole:

```tsx
import { formatCount } from "@/lib/format-count"

const { shown } = formatCount(count, { max: 99, locale })
```
