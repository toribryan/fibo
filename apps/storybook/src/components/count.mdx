# Count

A number formatted for a glance: capped at 99+, shortened to 1.2K, or signed
as +4. Screen readers hear the exact number, or a label.

<Canvas of={Stories.Default} />

## Features

- Caps with `max`, shortens with `notation="compact"`, and signs a count of
  things not shown with `plus`.
- Figures don't shift as the number changes.
- Announces the exact number when the shown one is capped or shortened, or
  a custom label such as “128 unread”.
- Text only. The surrounding part sets size, weight and color.

## Usage

```tsx
import { Badge } from "@/components/ui/badge"
import { Count } from "@/components/ui/count"

export function Unread({ count }: { count: number }) {
  return (
    <Badge variant="secondary">
      <Count value={count} max={99} label={(n) => `${n} unread`} />
    </Badge>
  )
}
```

For a count inside a sentence, such as “12 new messages”, use `formatCount`
and build the sentence around it, so it translates whole:

```tsx
import { formatCount } from "@/lib/format-count"

const { shown } = formatCount(count, { max: 99, locale })
```
