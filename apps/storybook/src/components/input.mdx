# Input

An input takes a single line of free text: a name, an email, a search term.
It fills the width of its container.

<Canvas of={Stories.WithLabel} />

## Features

- One line of text that fills the width of its container.
- Takes every native `input` prop and type, built on Base UI's Input.
- An invalid state through `aria-invalid`, with a destructive border and ring.
- State attributes for focus, filled and edited, for styling beyond the defaults.

## Usage

```tsx
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"

export function EmailField() {
  return (
    <div className="flex flex-col gap-2">
      <Label htmlFor="email">Email</Label>
      <Input
        id="email"
        type="email"
        autoComplete="email"
        placeholder="you@example.com"
      />
    </div>
  )
}
```

Give it a visible Label, the right `type`, and an `autoComplete` hint for
personal details.

## API reference

Input takes every native `input` prop except `size`, which sets its height
instead. Use `className` to set its width.
