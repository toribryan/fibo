# Input

An input takes a single line of free text: a name, an email, a search term.
It fills the width of its container.

<Playground of={Stories.WithLabel} />

<Install name="input" exports={["Input"]} />

## Usage

<UsageGuidelines
  guidelines={[
    "Give every input a visible Label above it. Placeholder text disappears on the first keystroke.",

## Accessibility

<UsageGuidelines
  guidelines={[
    <>
      Connect the label with <code>htmlFor</code> and <code>id</code>.
    </>,
    <>
      Mark errors with <code>aria-invalid</code> and point to the message with{" "}
      <code>aria-describedby</code>.
    </>,
    <>
      Add <code>autoComplete</code> for personal details so browsers and
      password managers can fill them.
    </>,
  ]}
/>

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <div className="flex w-56 flex-col gap-2">
            <Label htmlFor="rule-email">Email</Label>
            <Input id="rule-email" placeholder="you@example.com" />
          </div>
        ),
        description:
          "Use a label for the question and a placeholder for an example.",
      },
      negative: {
        component: <Input className="w-56" placeholder="Email" />,
        description:
          "Don't use the placeholder as the label. It vanishes as soon as people type.",
      },
    },
  ]}
/>
