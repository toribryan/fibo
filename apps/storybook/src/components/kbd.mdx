# Kbd

Kbd shows a key, or a keyboard shortcut, in running text or next to the
command it triggers.

<Canvas of={Stories.Default} />

## Features

- A `<kbd>` element, so the key is marked up as keyboard input.
- KbdGroup joins keys into a combination, the way HTML nests `<kbd>` for a
  shortcut.
- Takes an icon for symbol keys such as Command or the arrows.
- Sits on the text line without changing its height.

<Install name="kbd" exports={["Kbd", "KbdGroup"]} />

## Usage

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"

export function SearchHint() {
  return (
    <p>
      Press{" "}
      <KbdGroup>
        <Kbd>Ctrl</Kbd>
        <span>+</span>
        <Kbd>K</Kbd>
      </KbdGroup>{" "}
      to search.
    </p>
  )
}
```

Nest keys in a KbdGroup for a combination, and show Cmd on a Mac and Ctrl
elsewhere.
