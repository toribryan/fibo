# Kbd

Kbd shows a key or keyboard shortcut, in running text or beside the command
it triggers.

<Canvas of={Stories.Default} />

## Features

- Renders a `<kbd>` element.
- KbdGroup joins keys into a combination, as HTML nests `<kbd>` for a
  shortcut.
- Takes an icon for symbol keys such as Command or the arrows.
- Sits on the text line without changing its height.

## Usage

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"

export function SearchHint() {
  return (
    <p>
      Press{" "}
      <KbdGroup>
        <Kbd>Ctrl</Kbd>
        <span>+</span>
        <Kbd>K</Kbd>
      </KbdGroup>{" "}
      to search.
    </p>
  )
}
```

Nest keys in a KbdGroup for a combination.
