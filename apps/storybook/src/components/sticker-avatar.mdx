# Sticker avatar

An avatar cut out like a die-cut sticker, with a white paper edge that
follows a transparent image's shape and a slight per-sticker tilt.

<Canvas of={Stories.Default} />

## Features

- Follows the image's outline when its border is transparent; a photo with a
  background becomes a round sticker.
- Draws the edge once on a canvas when the image loads, then shows a plain
  image, so fifty stickers cost no more than fifty avatars.
- Tilts by a stable angle derived from the name, and lifts on hover or when a
  `group/sticker` row is hovered.
- Takes a [Status dot](?path=/docs/base-components-display-status-dot--docs)
  as a child, sets it on the corner turned against the tilt like a small
  sticker of its own, and adds its label to the sticker's name.

## Usage

```tsx
import { StatusDot } from "@/components/ui/status-dot"
import { StickerAvatar } from "@/components/ui/sticker-avatar"

export function Member({ user }: { user: User }) {
  return (
    <StickerAvatar name={user.name} src={user.cutoutUrl} size={40}>
      <StatusDot status={user.status} />
    </StickerAvatar>
  )
}
```

Pass an image with its background already removed. Cutting a subject out in
the browser takes a 40 to 170 MB model, so do it once on upload, on a server,
or let people bring their own. Cross-origin images need CORS headers for the
edge to be cut; without them the sticker falls back to round.

### Tokens

`--sticker-edge` is white and `--sticker-ink` near-black in both themes,
since paper doesn't change with the theme. A hairline and `--sticker-shadow`,
also fixed across themes, keep the white edge visible on a light page.

A StatusDot's disc is the page color, not paper. Its `success` (present),
`warning` (away) and `muted-foreground` (offline) tokens are tuned to clear
the 3:1 non-text contrast on the page color in each theme; on white paper
the dark-theme ones would not. `variant="mono"` draws the marks in the
foreground color instead.
