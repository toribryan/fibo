# Sticker avatar

An avatar cut out like a die-cut sticker. A white paper edge follows the
shape of a transparent image, each sticker sits at its own slight angle, and
status is a small sticker of its own on the corner.

<Canvas of={Stories.Default} />

## Features

- Follows the image's own outline when its border is transparent, and turns a
  photo with a background into a round sticker.
- Draws the edge once on a canvas when the image loads, then shows a plain
  image, so a list of fifty stickers costs no more than fifty avatars.
- Tilts by a stable angle from the name and lifts on hover, or when a row with
  `group/sticker` is hovered.
- Tells status apart by shape, a dot for present, a crescent for away and a
  ring for offline, and colours it with fibo's status tokens.

## Usage

```tsx
import { StickerAvatar } from "@/components/ui/sticker-avatar"

export function Member({ user }: { user: User }) {
  return (
    <StickerAvatar
      name={user.name}
      src={user.cutoutUrl}
      status={user.status}
      size={40}
    />
  )
}
```

Pass an image with its background already removed. Cutting a subject out in
the browser takes a 40 to 170 MB model, so do it once on upload, on a server,
or let people bring their own. Images on another host need CORS headers for
the edge to be cut; without them the sticker falls back to round.

## Tokens

`--sticker-edge` is white and `--sticker-ink` is near-black in both themes.
That is deliberate: a sticker is paper, and paper doesn't change colour when
the room gets dark. A hairline and a shadow keep the white edge visible on a
light page.

The status sticker is the exception. Its disc is the page colour, not paper,
because it is coloured with fibo's semantic tokens: `success` for present,
`warning` for away and `muted-foreground` for offline. Those tokens are tuned
for the page in each theme, so on the page colour they clear the 3:1 that
non-text marks need. On white paper the dark-theme ones would not. Set
`statusColor={false}` to draw the marks in the foreground colour instead.
