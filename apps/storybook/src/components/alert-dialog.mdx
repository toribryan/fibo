# Alert dialog

A modal question before a step that can't be undone, such as deleting a
project: confirm or cancel.

<Canvas of={Stories.Default} />

## Features

- `alertdialog` role, announced as a question that needs an answer.
- Cancel takes focus on open, so Enter alone never confirms.
- No close button and no click-outside dismiss. Only Cancel or Escape leaves.
- Dialog's look and motion, `sm` by default.

## Usage

```tsx
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@/components/ui/alert-dialog"
import { Button } from "@/components/ui/button"

export function DeleteProject({ onDelete }: { onDelete: () => void }) {
  return (
    <AlertDialog>
      <AlertDialogTrigger render={<Button variant="outline" />}>
        Delete project
      </AlertDialogTrigger>
      <AlertDialogContent>
        <AlertDialogHeader>
          <AlertDialogTitle>Delete Atlas redesign?</AlertDialogTitle>
          <AlertDialogDescription>
            Its files and comments are deleted for everyone. This can't be
            undone.
          </AlertDialogDescription>
        </AlertDialogHeader>
        <AlertDialogFooter>
          <AlertDialogCancel>Cancel</AlertDialogCancel>
          <AlertDialogAction variant="destructive" onClick={onDelete}>
            Delete project
          </AlertDialogAction>
        </AlertDialogFooter>
      </AlertDialogContent>
    </AlertDialog>
  )
}
```

Cancel goes before the action in the footer, since it takes focus. Both
close the dialog. For an action that has to finish first, control `open` and
close it when the work is done.

## API reference

AlertDialog takes Base UI's Alert Dialog Root props, such as `open`,
`defaultOpen` and `onOpenChange`. AlertDialogContent takes the Popup's props
plus `size` and `container`. AlertDialogAction and AlertDialogCancel take
Button's `variant` and `size`.
