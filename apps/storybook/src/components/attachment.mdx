# Attachment

Attachment shows one file someone has added: a one-line chip with the name
and size, or a thumbnail for an image, each with its upload status.

<Canvas of={Stories.Default} />

## Features

- `type` picks the shape: `file` is a chip, `image` is a 56px thumbnail.
- `status` follows an upload: `ready`, `loading` or `error`.
- Remove and retry buttons appear when you pass `onRemove` and `onRetry`.
- Shows an upload but never runs one, so it fits a chat draft, a form or a
  sent message.

## Usage

```tsx
import { Attachment } from "@/components/ui/attachment"

type Upload = {
  id: string
  file: File
  preview?: string
  status: "ready" | "loading" | "error"
}

export function Uploads({ uploads, remove, retry }: Props) {
  return (
    <ul className="flex flex-wrap gap-2">
      {uploads.map((upload) => (
        <li key={upload.id}>
          <Attachment
            type={upload.preview ? "image" : "file"}
            status={upload.status}
            name={upload.file.name}
            size={upload.file.size}
            src={upload.preview}
            onRemove={() => remove(upload.id)}
            onRetry={() => retry(upload.id)}
          />
        </li>
      ))}
    </ul>
  )
}
```

Whoever runs the upload owns `status`; Attachment only shows it.

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <Attachment
            status="error"
            name="drift-report.csv"
            error="Too large"
            onRetry={() => {}}
            onRemove={() => {}}
          />
        ),
        description: "Say what went wrong in a few words, and offer retry.",
      },
      negative: {
        component: (
          <Attachment
            status="error"
            name="drift-report.csv"
            error="The server returned 413 Payload Too Large"
            onRemove={() => {}}
          />
        ),
        description: "Don't show a raw error. It squeezes out the file name.",
      },
    },
  ]}
/>
