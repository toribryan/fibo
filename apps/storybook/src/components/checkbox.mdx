# Checkbox

A checkbox turns one option on or off, or picks any number of options from a
list. The change applies when the form is submitted.

<Playground of={Stories.Default} />

## Import

<Install name="checkbox" exports={["Checkbox"]} />

## Usage

<UsageGuidelines
  guidelines={[
    "Always pair a checkbox with a visible Label. The label is part of the hit area.",
    "Write labels as positive statements, so checked means yes.",
    "Stack options in a column. Rows of checkboxes are hard to scan.",
    "For a setting that applies immediately, use a switch instead.",
  ]}
/>

## Accessibility

<UsageGuidelines
  guidelines={[
    <>
      Connect the label with <code>htmlFor</code> and <code>id</code>, or wrap
      the checkbox in the Label.
    </>,
    "The hit area extends past the 16px box on every side, so it meets the 24px minimum target.",
    <>
      Mark errors with <code>aria-invalid</code>. The box turns destructive and
      keeps its focus ring.
    </>,
  ]}
/>

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <div className="flex items-center gap-2">
            <Checkbox id="rule-yes" defaultChecked />
            <Label htmlFor="rule-yes">Email me when someone replies</Label>
          </div>
        ),
        description: "Phrase the label so ticking it turns something on.",
      },
      negative: {
        component: (
          <div className="flex items-center gap-2">
            <Checkbox id="rule-no" />
            <Label htmlFor="rule-no">Don't stop sending me emails</Label>
          </div>
        ),
        description:
          "Don't use negatives. People have to work out what checked means.",
      },
    },
  ]}
/>
