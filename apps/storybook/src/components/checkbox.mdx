# Checkbox

A checkbox turns one option on or off, or picks any number of options from a
list. The change applies when the form is submitted.

<Canvas of={Stories.Default} />

## Features

- Checked, unchecked and indeterminate states, built on Base UI's Checkbox.
- The hit area reaches past the 16px box to meet the 24px minimum target.
- Works with a Label beside it or wrapped around it.
- An invalid state through `aria-invalid` that keeps the focus ring.

## Examples

### Checked

`defaultChecked` starts it ticked.

<Canvas of={Stories.Checked} />

### Indeterminate

`indeterminate` shows a dash for a group that's partly on, such as a select
all checkbox with some rows selected. Screen readers hear “mixed”.

<Canvas of={Stories.Indeterminate} />

### Disabled

`disabled` dims the box and blocks the pointer.

<Canvas of={Stories.Disabled} />

## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox"
import { Label } from "@/components/ui/label"

export function Replies() {
  return (
    <div className="flex items-center gap-2">
      <Checkbox id="replies" defaultChecked />
      <Label htmlFor="replies">Email me when someone replies</Label>
    </div>
  )
}
```

Pass `checked` and `onCheckedChange` to control it, or `defaultChecked` to let
it keep its own state.

## Guidelines
