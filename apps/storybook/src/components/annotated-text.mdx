# Annotated text

Hand-drawn marks on a word or phrase (underline, circle, box, strike,
highlight), plus a sticker chip that sets a word in a pill and can cycle
through several.

<Canvas of={Stories.Default} />

## Features

- Ten marks, drawn as SVG in the text's own pixels, so they keep their
  proportions at any type size and never stretch.
- Wobble seeded from the text: a phrase looks the same on every render and
  device, and two phrases differ.
- Optional draw-in on first scroll into view, with a `delay` for staging.
- `AnnotatedTextChip` and `AnnotatedTextCycle`: a word in a pill with a
  sticker, still or cycling.

CSS transitions.

## Examples

### Variants

`highlight` sits behind the text. Every other mark is drawn over or around
it.

<Canvas of={Stories.Variants} />

### Tones

`tone` colors a mark that carries meaning: a struck-out price in
destructive, a fixed figure in success. A highlight takes the quiet tint of
its tone.

<Canvas of={Stories.Tones} />

### Sizes

Offsets and strokes scale with the text's height.

<Canvas of={Stories.Sizes} />

### Draw in

`animate` draws the mark in once it's mostly in view. `delay` stages
several marks in order.

<Canvas of={Stories.DrawIn} />

### Sticker chips

`AnnotatedTextChip` puts a sticker at the pill's start, tilted by an amount
derived from the word. An emoji or `<img>` gets a white die-cut edge round its
outline. A line icon is printed in ink on a paper tile, since an edge round
every stroke would read as an outline.

<Canvas of={Stories.Chip} />

### Cycling chips

`AnnotatedTextCycle` swaps word and sticker in one pill, which springs to
fit. It pauses under the pointer and, by default, runs through once and
settles on the last item.

<Canvas of={Stories.Cycle} />

### In prose

At body size, one or two marks per paragraph.

<Canvas of={Stories.InProse} />

## Usage

```tsx
import {
  AnnotatedText,
  AnnotatedTextChip,
  AnnotatedTextCycle,
} from "@/components/ui/annotated-text"

export function Hero() {
  return (
    <h1>
      Design <AnnotatedText variant="circle">systems</AnnotatedText> that ship
      with{" "}
      <AnnotatedTextCycle
        items={[
          { label: "agents", icon: <BotIcon /> },
          { label: "anything", icon: <SparklesIcon /> },
        ]}
      />
    </h1>
  )
}
```

```ts
type AnnotatedTextCycleItem = { label: string; icon?: React.ReactNode }
```

Keep annotated phrases short. They never wrap, since a mark is drawn round
one line.

`AnnotatedTextChip` is a span with `data-slot="annotated-text-chip"`, holding
the sticker (`annotated-text-chip-icon`) and the text.
`AnnotatedTextCycle` is a span with `data-slot="annotated-text-cycle"` and
`data-index`, holding a visually hidden label and the animated pill.
