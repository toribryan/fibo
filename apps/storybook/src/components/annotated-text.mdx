# Annotated text

Marks a word or phrase the way a pen would: underlined, circled, boxed,
struck out or run over with a highlighter. A sticker chip sets a word apart
in a pill, and can cycle through a few words in the same spot.

<Canvas of={Stories.Default} />

## Features

- Ten hand-drawn marks, drawn as SVG in the text's own pixels, so they keep
  their proportions from a caption to a display heading and never stretch.
- A steady wobble seeded from the text: the same phrase looks the same on
  every render and device, and two phrases don't wobble alike.
- An optional draw-in the first time the text scrolls into view, with a
  delay for staging several marks in order.
- `AnnotatedTextChip` and `AnnotatedTextCycle` for a word in a pill with a
  sticker beside it, still or cycling.

Installs `motion`, which the cycling chip uses to slide words and resize the
pill. The marks themselves are CSS transitions.

## Examples

### Variants

Each `variant` is one kind of mark. `highlight` sits behind the text; every
other mark is drawn over or around it.

<Canvas of={Stories.Variants} />

### Tones

`tone` colors a mark when the mark means something: a struck-out price in
destructive, a fixed figure in success. A highlight takes the quiet tint of
its tone.

<Canvas of={Stories.Tones} />

### Sizes

Every offset and stroke is a share of the text's height, so the mark grows
with the type.

<Canvas of={Stories.Sizes} />

### Draw in

With `animate`, a mark draws itself in once it's mostly in view. `delay`
stages several marks so they read in order.

<Canvas of={Stories.DrawIn} />

### Sticker chips

`AnnotatedTextChip` sets a word in a pill with a sticker at its start. The
sticker takes a small tilt from the word. An emoji or an `<img>` is die-cut
with a white paper edge round its outline. A line icon is printed in ink on
a small paper tile, since an edge round every stroke would read as an
outline rather than a sticker.

<Canvas of={Stories.Chip} />

### Cycling chips

`AnnotatedTextCycle` swaps the word and sticker in one pill, and the pill
springs to fit. It pauses under the pointer, and by default runs through its
items once and settles on the last.

<Canvas of={Stories.Cycle} />

### In prose

At body size, a mark or two a paragraph is enough.

<Canvas of={Stories.InProse} />

## Usage

```tsx
import {
  AnnotatedText,
  AnnotatedTextChip,
  AnnotatedTextCycle,
} from "@/components/ui/annotated-text"

export function Hero() {
  return (
    <h1>
      Design <AnnotatedText variant="circle">systems</AnnotatedText> that ship
      with{" "}
      <AnnotatedTextCycle
        items={[
          { label: "agents", icon: <BotIcon /> },
          { label: "anything", icon: <SparklesIcon /> },
        ]}
      />
    </h1>
  )
}
```

```ts
type AnnotatedTextCycleItem = { label: string; icon?: React.ReactNode }
```

Keep an annotated phrase short. It never wraps, because a mark is drawn
round one line of text.

`AnnotatedTextChip` is a span with `data-slot="annotated-text-chip"`, holding
the sticker (`annotated-text-chip-icon`) and the text.
`AnnotatedTextCycle` is a span with `data-slot="annotated-text-cycle"` and
`data-index`, holding a visually hidden label and the animated pill.
