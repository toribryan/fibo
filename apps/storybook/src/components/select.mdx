# Select

A select picks one option from a list that opens on demand. It keeps a long
list of choices down to one line until someone needs it.

<Canvas of={Stories.Default} />

## Features

- Built on Base UI's Select, so it's announced as a combobox with a
  listbox, not as a button.
- The list opens over the trigger with the chosen option lined up on it, as
  native menus do.
- Groups with labels and separators for longer lists.
- Typeahead: with the list open, typing a letter jumps to the next option
  that starts with it.

## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"

const fruits = [
  { value: "apple", label: "Apple" },
  { value: "banana", label: "Banana" },
]

export function FruitPicker() {
  return (
    <Select items={fruits}>
      <SelectTrigger aria-label="Fruit" className="w-48">
        <SelectValue placeholder="Pick a fruit" />
      </SelectTrigger>
      <SelectContent>
        {fruits.map((fruit) => (
          <SelectItem key={fruit.value} value={fruit.value}>
            {fruit.label}
          </SelectItem>
        ))}
      </SelectContent>
    </Select>
  )
}
```

Pass `items` to the Select so the trigger shows an option's label, not its
raw value, before the list has ever opened.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Use a select for one choice from about six or more options, or when space is tight.",
    "For fewer options that people should compare, show them all with a radio group.",
    "Write a placeholder that says what to pick, like “Pick a timezone”, or start with a sensible option chosen.",
    "Group long lists under short labels, and sort options within each group.",
    "If people need to search or type their own value, a select is the wrong part.",
  ]}
/>

<Tip>
  Set `alignItemWithTrigger={false}` on SelectContent to drop the list below the
  trigger instead of over it, as a menu would.
</Tip>

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <Select
            defaultValue="london"
            items={[
              { value: "berlin", label: "Berlin" },
              { value: "lisbon", label: "Lisbon" },
              { value: "london", label: "London" },
              { value: "new-york", label: "New York" },
              { value: "tokyo", label: "Tokyo" },
              { value: "sydney", label: "Sydney" },
            ]}
          >
            <SelectTrigger aria-label="Timezone" className="w-44">
              <SelectValue />
            </SelectTrigger>
            <SelectContent>
              {[
                "Berlin",
                "Lisbon",
                "London",
                "New York",
                "Tokyo",
                "Sydney",
              ].map((city) => (
                <SelectItem
                  key={city}
                  value={city.toLowerCase().replace(" ", "-")}
                >
                  {city}
                </SelectItem>
              ))}
            </SelectContent>
          </Select>
        ),
        description:
          "Use a select for a longer list, starting on a sensible choice.",
      },
      negative: {
        component: (
          <Select
            items={[
              { value: "yes", label: "Yes" },
              { value: "no", label: "No" },
            ]}
          >
            <SelectTrigger aria-label="Subscribe" className="w-44">
              <SelectValue placeholder="Subscribe?" />
            </SelectTrigger>
            <SelectContent>
              <SelectItem value="yes">Yes</SelectItem>
              <SelectItem value="no">No</SelectItem>
            </SelectContent>
          </Select>
        ),
        description:
          "Don't hide two options behind a click. Show them with a radio group, or use a checkbox.",
      },
    },
  ]}
/>

## API reference

Select takes every prop of Base UI's `Select.Root`, including `value`,
`defaultValue`, `onValueChange`, `items`, `name` and `disabled`. SelectContent
also takes the positioning props `side`, `sideOffset`, `align`,
`alignOffset` and `alignItemWithTrigger`.
