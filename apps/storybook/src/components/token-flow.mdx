# Token flow

Shows a color moving through the token tiers: raw value, primitive, semantic
role.

<Canvas of={Stories.WithUse} />

## Features

- One row per role, its three tiers joined by wires.
- A pulse runs along each wire while the plate is on screen.
- Rows with a `dark` pair scramble to their dark values when the theme changes;
  the role's name stays put. Try the toolbar theme switch.
- `showUse` prints what each role is for under its chip.

## Installation

<Install name="token-flow" exports={["TokenFlow", "type TokenRow"]} />

No animation library; the pulse and scramble use the Web Animations API and
`requestAnimationFrame`.

## Usage

```tsx
import { TokenFlow } from "@/components/ui/token-flow"

export function PrimaryToken() {
  return (
    <TokenFlow
      rows={[
        {
          base: "oklch(0.205 0 0)",
          primitive: "neutral-900",
          semantic: "bg-primary",
          dark: { base: "oklch(0.985 0 0)", primitive: "neutral-50" },
        },
      ]}
    />
  )
}
```

Name the role as it's written in code.

## API reference

Each row takes `base`, `primitive` and `semantic`, plus an optional `use` and a
`dark` pair for roles that resolve differently in the dark theme.
