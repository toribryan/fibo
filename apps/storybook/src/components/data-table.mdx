# Data table

Data table is the one table for lists people work through: selection in the
first column, six cell types, locked rows that say why, and columns pinned to
either edge. It matches the Data table in the Figma library.

<Canvas of={Stories.Default} />

## Features

- A checkbox column with select all, which skips locked rows and shows a
  dash while only some rows are selected.
- Shift+click selects a range, and Escape clears the selection.
- Six cell types: primary, text, person, status, numeric and actions. A
  second line on a cell makes its row 52 pixels.
- Columns pinned to the start or end, with shadows while there's more to
  scroll. Pinning switches off under 32rem.
- Selection changes are announced: “3 agents selected”, “Selection cleared”.
- One toolbar row for every action: filters and create actions while idle,
  then the selection and bulk actions in the same place while rows are
  selected, with Select all matching for the rows on other pages.
- Under 32rem it keeps working: the table scrolls under an icon-only
  toolbar, or each row becomes a card. Sort and filters move into a sheet.

## Usage

```tsx
import { Badge } from "@/components/ui/badge"
import {
  DataTable,
  DataTableBody,
  DataTableCell,
  DataTableContent,
  DataTableHead,
  DataTableHeader,
  DataTableRow,
  useDataTableSelection,
} from "@/components/ui/data-table"

export function Agents({ agents }: { agents: Agent[] }) {
  const selection = useDataTableSelection()
  return (
    <DataTable
      aria-label="Agents"
      rowIds={agents.map((agent) => agent.id)}
      noun={{ one: "agent", other: "agents" }}
      {...selection}
    >
      <DataTableContent>
        <DataTableHeader>
          <DataTableHead type="person" pinned="start">
            Agent
          </DataTableHead>
          <DataTableHead type="status">Status</DataTableHead>
        </DataTableHeader>
        <DataTableBody>
          {agents.map((agent) => (
            <DataTableRow
              key={agent.id}
              id={agent.id}
              lockedReason={
                agent.isAdmin ? "Admins can't be removed" : undefined
              }
            >
              <DataTableCell
                type="person"
                pinned="start"
                avatar={{ src: agent.photo, fallback: agent.initials }}
              >
                {agent.name}
              </DataTableCell>
              <DataTableCell type="status">
                <Badge variant="success">{agent.status}</Badge>
              </DataTableCell>
            </DataTableRow>
          ))}
        </DataTableBody>
      </DataTableContent>
    </DataTable>
  )
}
```

Give each head the same `type` and `pinned` as its column's cells. The first
column is primary or person: its text names the row's checkbox.

```ts
type DataTableSelection = Set<string> | "all"
```

`"all"` means every row that matches, on every page. Changing one row while
everything is selected keeps this page's rows and drops the rest.

<Canvas of={Stories.Picker} />

### Narrow, scroll

The default under 32rem: the table scrolls sideways, pinning switches off,
the search fills the toolbar, and sort and filters move behind Filters.

<Canvas of={Stories.NarrowScroll} />

### Narrow, cards

`narrowLayout="cards"`: each row becomes a card, select all moves into the
toolbar, and bulk actions show their icons. Cards need a DataTableToolbar,
since that's where select all goes.

Narrow, the toolbar keeps the count, Clear and bulk actions. Select all
matching and Show selected only aren't offered, as in the Figma library.
Keep filter values in state you own: the controls move between the toolbar
and the Filters sheet as the width crosses 32rem.

## API reference

DataTable takes the selection props below. Head and Cell take `type` and
`pinned`; Cell also takes `secondary`, `icon` and `avatar`; Row takes `id`
and `lockedReason`. Every part also takes the props of the element it
renders.
