# Command menu

A search dialog of grouped commands. Cmd+K on macOS or Ctrl+K elsewhere
opens it from anywhere on the page, typing narrows every group at once, and
Enter runs the highlighted command.

<Canvas of={Stories.Default} />

## Features

- Opens from its search button or from a keyboard shortcut, Cmd+K or Ctrl+K
  by default, which also closes it.
- Searches labels and hidden keywords across every group, and hides groups
  with no matches.
- The first match is always highlighted, so typing and pressing Enter is
  enough.
- Items can show an icon and a shortcut, and can be disabled.

## Usage

```tsx
import { useRouter } from "next/navigation"
import {
  CommandMenu,
  type CommandMenuGroup,
} from "@/components/ui/command-menu"

export function AppCommands() {
  const router = useRouter()
  const groups: CommandMenuGroup[] = [
    {
      label: "Go to",
      items: [
        {
          value: "inbox",
          label: "Inbox",
          onSelect: () => router.push("/inbox"),
        },
        {
          value: "settings",
          label: "Settings",
          shortcut: ["⌘", ","],
          onSelect: () => router.push("/settings"),
        },
      ],
    },
  ]
  return <CommandMenu groups={groups} />
}
```

Each item runs its own `onSelect`, then the menu's `onSelect` gets the item,
and the menu closes. Give every item a `value` that is unique across the
whole menu.

```ts
type CommandMenuGroup = {
  label: string
  items: {
    value: string
    label: string
    icon?: React.ReactNode
    shortcut?: string[]
    keywords?: string[]
    disabled?: boolean
    onSelect?: () => void
  }[]
}
```

Render one command menu per page. Its shortcut listens on the whole
document, so two menus with the same `hotkey` would both open.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Use it for moving around an app and running actions people would otherwise hunt for in menus.",
    "Start labels with a verb for actions (New file, Toggle theme) and use the plain name for places (Inbox, Settings).",
    "Put the commands people use most in the first group, and keep groups to a handful of items each.",
    "Add keywords for the words people might type instead: dark mode for Toggle theme, create for New file.",
    "Don't make it the only way to reach something. It speeds up people who know it's there.",
  ]}
/>

<Tip>
  A shortcut on an item is only a label. Wire the same keys up in your app, or
  leave `shortcut` off.
</Tip>

## Examples

### Default

The search button shows the shortcut for the platform. Cmd+K or Ctrl+K opens
the menu from anywhere on the page too.

<Canvas of={Stories.Default} />

### No matches

A search with no results says so, using `emptyText`.

<Canvas of={Stories.NoMatches} />

### Without hints

`hints={false}` drops the row of keyboard hints, for apps where people
already know the keys.

<Canvas of={Stories.WithoutHints} />

### Custom trigger

`trigger` swaps the search button for your own element.

<Canvas of={Stories.CustomTrigger} />

### Controlled

`trigger={null}` renders no trigger, and `open` with `onOpenChange` puts the
state in your hands, here opened by a button elsewhere on the page or the
shortcut.
