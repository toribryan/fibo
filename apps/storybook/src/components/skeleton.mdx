# Skeleton

A placeholder in the shape of content that's still loading.

<Canvas of={Stories.Default} />

## Features

- One element, sized and shaped with classes: a line, a circle, a card.
- A slow pulse that stops under reduced motion.
- No dependencies: a styled `div`.

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"

export function AuthorLoading() {
  return (
    <div className="flex items-center gap-3" aria-busy="true">
      <Skeleton className="size-10 rounded-full" />
      <Skeleton className="h-4 w-40" />
    </div>
  )
}
```

Match the size and shape of the incoming content so the layout doesn't shift
when it arrives.
