# Search input

A search box with a Cmd+K shortcut and a clear button, and a compact
trigger for a header whose search opens in a command menu.

<Canvas of={Stories.Default} />

## Features

- Cmd+K on macOS, Ctrl+K elsewhere, focuses the field from anywhere on the
  page. The key hint shows which, and hides on touch screens.
- Once there's a query, the hint gives way to a clear button. Escape clears
  first, then leaves the field.
- `SearchTrigger` is a ghost button with the icon and the hint, for a header
  where the search opens in a dialog. The shortcut presses it.
- Controlled through `value` and `onValueChange`, or left to keep its own
  query. Inside a Field, the FieldLabel names it.

`size="sm"` matches a small Button or Select, as in a toolbar. Inside a

## Usage

```tsx
import { useState } from "react"

import {
  CommandMenu,
  type CommandMenuGroup,
} from "@/components/ui/command-menu"
import { SearchInput, SearchTrigger } from "@/components/ui/search-input"

export function DocsSearch() {
  const [query, setQuery] = useState("")
  return (
    <SearchInput
      aria-label="Search docs"
      value={query}
      onValueChange={setQuery}
    />
  )
}

export function HeaderSearch({ groups }: { groups: CommandMenuGroup[] }) {
  return (
    <CommandMenu
      groups={groups}
      hotkey={null}
      trigger={<SearchTrigger aria-haspopup="dialog" />}
    />
  )
}
```

Give each page one shortcut: when two searches share it, the first one
mounted takes it.
