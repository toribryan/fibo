# Search input

A search box with a Cmd+K shortcut and a clear button, or the same search
folded into a small header button that opens a command menu.

<Canvas of={Stories.Default} />

## Features

- Cmd+K on macOS, Ctrl+K elsewhere, focuses the field from anywhere on the
  page. The key hint shows which, and hides on touch screens.
- Once there's a query, the hint gives way to a clear button. Escape clears
  first, then leaves the field.
- `type="button"` draws a ghost button with the icon and the hint, for a
  header where the search opens in a dialog. The shortcut presses it.
- Controlled through `value` and `onValueChange`, or left to keep its own
  query.

## Usage

```tsx
import { useState } from "react"

import {
  CommandMenu,
  type CommandMenuGroup,
} from "@/components/ui/command-menu"
import { SearchInput } from "@/components/ui/search-input"

export function DocsSearch() {
  const [query, setQuery] = useState("")
  return (
    <SearchInput label="Search docs" value={query} onValueChange={setQuery} />
  )
}

export function HeaderSearch({ groups }: { groups: CommandMenuGroup[] }) {
  return (
    <CommandMenu
      groups={groups}
      hotkey={null}
      trigger={<SearchInput type="button" aria-haspopup="dialog" />}
    />
  )
}
```

Give each page one shortcut: when two searches share it, the first one
mounted takes it.

## Guidelines

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: <SearchInput type="button" hotkey={null} />,

        component: (
          <Button variant="outline">

            Search
          </Button>

        description:
          "Don't build a search button by hand; it loses the shortcut and its hint.",
