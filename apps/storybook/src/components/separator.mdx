# Separator

A thin rule between groups of content, across or down, with an optional
label in the middle.

<Canvas of={Stories.Default} />

## Features

- Horizontal across its container, or vertical down the height of its row.
- Children make a labeled rule: a line, the label, a line. A text label is
  also its name for screen readers.
- A `separator` role with its orientation, from Base UI.

## Examples

### Vertical

Between items in a row, such as actions in a toolbar. It takes the row's
height.

## Usage

```tsx
import { Separator } from "@/components/ui/separator"

export function Day({ date }: { date: string }) {
  return <Separator>{date}</Separator>
}
```

Use space before a rule: reach for a separator only when groups would run
together without one.
