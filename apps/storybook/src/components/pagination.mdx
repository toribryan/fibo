# Pagination

Pagination moves through a long list one page at a time, and says which rows
are showing, such as “1 to 25 of 10,000 agents”.

<Canvas of={Stories.Default} />

## Features

- Previous and Next with the page and page count between them.
- The range of rows on this page, with thousands separators and a singular
  noun for one row.
- Controlled or uncontrolled, counting pages from 1.
- The ends are disabled but stay focusable, so keyboard focus isn't lost on
  the first or last page.

## Installation

<Install name="pagination" exports={["Pagination"]} />

It installs Button.

## Usage

```tsx
import { Pagination } from "@/components/ui/pagination"

export function AgentsFooter({ page, setPage }: Props) {
  return (
    <Pagination
      page={page}
      onPageChange={setPage}
      pageCount={400}
      pageSize={25}
      totalCount={10000}
      noun={{ one: "agent", other: "agents" }}
    />
  )
}
```

Pagination doesn't fetch or slice anything. It reports the page, and the app
loads the rows for it.

```ts
type PaginationNoun = string | { one: string; other: string }
```
