# Label

A label names a form control. Clicking it focuses or toggles the control, so
it also widens the hit area.

<Canvas of={Stories.Default} />

## Features

- Names a form control. Clicking it focuses or toggles the control.
- Dims with its control when the control is disabled.
- Lays out as a row with a gap, so an icon can sit beside the text.

## Installation

<Install name="label" exports={["Label"]} />

## Usage

```tsx
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"

export function NameField() {
  return (
    <div className="flex flex-col gap-2">
      <Label htmlFor="name">Full name</Label>
      <Input id="name" autoComplete="name" />
    </div>
  )
}
```

Match `htmlFor` to the control's `id`, or wrap the control in the label.
