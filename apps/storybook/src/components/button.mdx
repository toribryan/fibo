# Button

Buttons trigger an action with a single click: submitting a form, opening a
dialog, confirming or cancelling a step. The label says what will happen.

<Playground of={Stories.Default} />

## Usage

<UsageGuidelines
  guidelines={[
    "Use one default (primary) button per view. Every other action gets a lower emphasis variant.",
    "Keep labels to one to three words, in sentence case, starting with a verb.",
    <>
      Mark icons with <code>data-icon="inline-start"</code> or{" "}
      <code>"inline-end"</code> so the padding adjusts for them.
    </>,
    "Let the label set the width. Stretch a button only on narrow layouts where it spans the container.",
    "Keep 8px between buttons in a group.",
  ]}
/>

<Tip>
  For navigation, render Button as a link with{" "}
  <code>{'render={<a href="/pricing" />}'}</code> and{" "}
  <code>{"nativeButton={false}"}</code>. It keeps the look and gets link
  semantics.
</Tip>

## Accessibility

<UsageGuidelines
  guidelines={[
    <>
      Icon-only buttons need an <code>aria-label</code>. The icon is decorative.
    </>,
    <>
      Only disable a button when the reason is obvious nearby. Otherwise keep it
      enabled and explain what's missing on submit.
    </>,
    <>
      The focus ring is a 3px <code>ring-subtle</code> halo over a{" "}
      <code>ring</code> border, and it shows for keyboard focus only.
    </>,
  ]}
/>

not a solid red, so it never outshouts the primary action.

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <div className="flex gap-2">
            <Button variant="ghost">Cancel</Button>
            <Button>Save changes</Button>
          </div>
        ),
        description: "Pair one primary action with a quieter secondary one.",
      },
      negative: {
        component: (
          <div className="flex gap-2">
            <Button>Cancel</Button>
            <Button>Save changes</Button>
          </div>
        ),
        description:
          "Don't put two primary buttons side by side. Nothing tells people which one matters.",
      },
    },
    {
      positive: {
        component: <Button>Create project</Button>,
        description: "Use sentence case and a verb that names the outcome.",
      },
      negative: {
        component: <Button>CREATE PROJECT!</Button>,
        description: "Don't use all caps, title case or punctuation.",
      },
    },
    {
      positive: {
        component: (
          <Button variant="outline">
            Continue
            <ArrowRightIcon data-icon="inline-end" />
          </Button>
        ),
        description: "Put a directional icon after the label it points from.",
      },
      negative: {
        component: (
          <div className="flex gap-2">
            <Button variant="secondary">Yes</Button>
            <Button variant="secondary">No</Button>
          </div>
        ),
        description:
          "Don't use vague labels that force people to reread the question.",
      },
    },
  ]}
/>
