# Button

Triggers an action: submitting a form, opening a dialog, confirming or
canceling a step.

<Canvas of={Stories.Default} />

## Features

- Six variants, from the filled primary to a plain link, in four text sizes and
  four icon sizes.
- `iconStart` and `iconEnd` take an icon component and pull the padding in
  on their side.
- `loading` swaps the start icon for a spinner, blocks presses and keeps
  focus on the button.
- Renders as a link, or any other element, through Base UI's `render` prop.
- `destructive` is a red tint, so it never outshouts the primary action.

## Examples

### Kinds

Six variants, from most to least emphasis.

<Canvas of={Stories.AllVariants} />

### Sizes

Four text sizes, `xs` to `lg`, and four square `icon` sizes to match.

<Canvas of={Stories.AllSizes} />

### With an icon

`iconStart` or `iconEnd` takes the icon component and tightens the padding on
that side. An icon placed as a child with `data-icon="inline-start"` does the
same.

<Canvas of={Stories.WithIcon} />

### Loading

`loading` shows a spinner and sets `aria-busy`. The button stays focusable,
so focus isn't lost while the action runs, but presses do nothing.

<Canvas of={Stories.Loading} />

### Fill width

`fillWidth` stretches the button to its container, for narrow forms.

<Canvas of={Stories.FillWidth} />

### Icon only

An `icon` size, named with `aria-label`.

<Canvas of={Stories.IconOnly} />

### Disabled

`disabled` dims the button and blocks the pointer.

## Usage

```tsx
import { Button } from "@/components/ui/button"

export function Actions() {
  return (
    <div className="flex gap-2">
      <Button variant="ghost">Cancel</Button>
      <Button>Save changes</Button>
    </div>
  )
}
```

One default button per view. Every other action takes a quieter variant.

## Accessibility

<UsageGuidelines
  guidelines={[
    <>
      Icon-only buttons need an <code>aria-label</code>. Icons are{" "}
      <code>aria-hidden</code>.
    </>,
    <>
      A loading button sets <code>aria-busy</code> and{" "}
      <code>aria-disabled</code> and stays in the tab order. Announce the
      result, such as with a toast, when the action finishes.
    </>,
    <>
      Disable a button only when the reason is obvious nearby. Otherwise keep it
      enabled and explain what's missing on submit.
    </>,
    <>
      The focus ring is a 3px <code>ring-subtle</code> halo over a{" "}
      <code>ring</code> border, and it shows for keyboard focus only.
    </>,
  ]}
/>
