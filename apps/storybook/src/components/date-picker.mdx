# Date picker

A field that opens a calendar. `DatePicker` picks one day and closes;
`DateRangePicker` picks a start and an end, with presets, and applies them
together. On a phone both open as a drawer from the bottom.

## Features

- `DatePicker` picks as soon as a day is chosen. Presets such as Tomorrow
  are there when you pass them.
- `DateRangePicker` keeps a draft: two picks, a live preview between them,
  the range and its length in the footer, then Apply. Cancel and Escape
  leave the value as it was.
- Presets are functions of today, so "Last 7 days" stays right tomorrow.
  They're clamped to `minDate` and `maxDate`, and turned off when none of
  their range is allowed.
- Below the `sm` breakpoint the panel is a drawer: presets in a chip row,
  months in one vertical scroll with 44 pixel days, Apply at the bottom.
  `type` forces either.

## Usage

```tsx
import { DateRangePicker, type DateRange } from "@/components/ui/date-picker"

export function ReportPeriod() {
  const [range, setRange] = useState<DateRange | null>(null)
  return (
    <DateRangePicker
      label="Report period"
      value={range}
      onChange={setRange}
      maxDate={new Date()}
    />
  )
}
```

Presets are a label and a function of today:

```ts
type DateRangePreset = {
  label: string
  range: (today: Date) => { from: Date; to: Date }
}

type DatePreset = {
  label: string
  date: (today: Date) => Date
}
```

Give each picker a `label` that says what the dates are for. It names the
trigger and the panel, and the trigger reads it with the value.
