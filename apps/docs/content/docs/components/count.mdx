## When to use it

Use Count for a number people take in at a glance: capped with `max`,
shortened with `notation="compact"`, or signed with `plus` for things not
shown. Figures don't shift as the number changes, and screen readers hear the
exact number or a label such as “128 unread”. It's text only; the surrounding
part sets size, weight and color.

## Installation

<Install name="count" exports={["Count", "formatCount", "type CountProps"]} />

Installs the `formatCount` helper into `lib/`, for counts inside a sentence,
such as “12 new messages”. Build the sentence around it, so it translates
whole.

## Accessibility

- The number shown is hidden from screen readers when it differs from what
  they hear, so 99+ is read as 128, or as your label.
- `label={null}` hides the count from screen readers, for a part whose name
  already says it, such as a reaction pill.
