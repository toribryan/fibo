## When to use it

Use Command menu for navigation and for actions otherwise buried in menus. An
item with `items` opens a nested page instead of running, commands you run
float to the top under Recent, and searching from the first page reaches
every page. Cmd+K on macOS, Ctrl+K elsewhere, toggles it; the examples here
set `hotkey={null}` so they don't clash with this site's search.

## With preview

Files and people have a `preview`, so the dialog widens and a pane follows
the highlight. Items without one show a placeholder. The pane is hidden below
the `sm` breakpoint.

## Inset

`variant="inset"` sets the list in a card inside a muted shell. The search
box and keyboard hints sit on the shell with no rules between them.

## Controlled

`trigger={null}` renders no trigger. `open` and `onOpenChange` control the
state, here from an external button.

## Guidelines

  guidelines={[

## Accessibility

- A modal dialog named by label. Focus moves to the search box on open, is
  trapped while open, and returns to the trigger on close.
- With `modal` set to `false` focus is neither trapped nor moved. Reserve it
  for a menu that is part of the page, such as a demo in a card.
- The search box is a combobox pointing at the highlighted command with
  aria-activedescendant, so screen readers announce each one as the arrows
  move.
- On a page, the search box is named after it (Command menu, Change theme)
  and the back button names its destination. Items that open a page say so.
- Escape steps back one level: clear the search, leave the page, then close
  the menu without running anything.
- Searches announce the result count. The preview pane is a polite live
  region.
- Keyboard hints are hidden from screen readers, which announce combobox keys
  themselves.
- All built-in text is translatable through `labels`, alongside
  `placeholder`, `emptyText` and `label`.
