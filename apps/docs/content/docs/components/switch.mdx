## When to use it

Use Switch for a setting that applies the moment it changes, with no save
button. `checked` and `onCheckedChange` control it; `defaultChecked` leaves it
uncontrolled. Save the change as soon as it fires. If the change applies only
on form submit, use a checkbox.

## Accessibility

- Announced as a switch, on or off, with `aria-checked`. Space toggles it.
- Link a Label with `htmlFor` and `id`, or set `aria-label` when there's no
  visible label.
- The hit area extends past the track on every side to meet the 24px minimum
  target.
- The thumb's position shows the state as well as the track's color, so state
  never relies on color alone.
