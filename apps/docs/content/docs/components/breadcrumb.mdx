## When to use it

Use Breadcrumb at the top of a page more than two levels deep, so people see
where they are and can step back up. When people often move between
siblings, such as databases or projects, make that level a
`BreadcrumbMenuTrigger` inside a Menu, labeled with the current choice.

## Links

A plain trail that ends on the current page. `BreadcrumbLink` takes `render`,
so a router's link keeps the styles.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Put it at the top of the page, above the title.",
    "Start from the highest level people navigate from, not the site's home, when the app has one.",
    "Use one menu segment per trail, on the level people switch most: a database, a project, a workspace.",
    "Keep segment names short; long ones truncate.",
    "Collapse the middle of a trail deeper than four levels with an ellipsis.",
  ]}
/>

## Accessibility

- The root is a nav named "Breadcrumb". Pass `aria-label` to rename it.
- The levels are an ordered list; separators are hidden from screen readers.
- `BreadcrumbPage` carries `aria-current="page"`.
- The ellipsis reads as "More pages". Make it a menu trigger if people need to
  reach the hidden levels.
- The menu trigger is a button named by its label, announced as having a
  menu. If you add `aria-label`, keep the visible label in it.
