## When to use it

Use Reactions for one-tap emoji responses to content, inline under it or
floating in a corner of the page. One tap reacts or takes it back, with a
particle burst. A picker offers six common reactions plus any already on the
item; it's a Base UI popover, so a card that clips its overflow can't cut it
off. It works controlled or uncontrolled.

## Floating

`type="floating"` pins a bar to a viewport corner, chosen with `position`.
Here a transformed wrapper stands in for the viewport, so the bar pins to the
preview instead of the page.

## Accessibility

- Each pill is a toggle button named by the reaction's label and count, such
  as "Heart, 3 reactions", with `aria-pressed` for whether you've reacted.
  The emoji itself is hidden from screen readers.
- A polite live region announces each change: "Added Heart", "Removed Heart".
  On the floating bar, with counts on, it adds the new total: "Added Heart,
  13 reactions in total".
- With showCounts off, pills are named by label alone, matching what sighted
  users see.
- Choices already picked show as pressed in the picker.
- Arrow keys, Home and End move through the choices. Escape closes the picker
  and returns focus to its trigger; tabbing away closes it too.
- Particles and pill motion switch off under prefers-reduced-motion.
- Override `triggerLabel` and `panelLabel` for other languages.
