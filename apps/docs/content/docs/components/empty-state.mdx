## When to use it

Use Empty state where a table, list, menu or page has nothing to show. The
title says what's missing, the action what to do, and the description
explains why only when it isn't obvious. `size="sm"` fits a line in a menu
or popover; `default` fits a table, list or page. Data table and Message list
use it already.

## Small, in a menu

Title only, in muted text. Command menu and Filter menu use this for no
results.

<Preview>
  <div className="w-64 rounded-xl border border-border bg-popover shadow-lg">
    <EmptyState size="sm">
      <EmptyStateTitle>{"No matching filters"}</EmptyStateTitle>
    </EmptyState>
  </div>
</Preview>

## No matches

When a search or filter hid everything, offer a way back.

<Preview>
  <div className="w-96 rounded-lg border border-border">
    <EmptyState>
      <EmptyStateMedia>
        <SearchXIcon />
      </EmptyStateMedia>
      <EmptyStateTitle>{"No matching members"}</EmptyStateTitle>
      <EmptyStateDescription>
        {"Try another search, or clear the filters."}
      </EmptyStateDescription>
      <EmptyStateActions>
        <Button variant="outline" size="sm">
          Clear filters
        </Button>
      </EmptyStateActions>
    </EmptyState>
  </div>
</Preview>

## Guidelines

<UsageGuidelines
  guidelines={[
    "Name what's missing in the title: No members yet, not Nothing here.",
    "Distinguish first-run empty from no matches. One invites adding something, the other clearing a search.",
    "One primary action at most. A second is outline or ghost.",
    "Omit the icon in small empty states; menus have no room for it.",
  ]}
/>

## Accessibility

- Title and description are plain text, read in document order.
- The icon is hidden from screen readers.
- When an empty state replaces results during typing, put it in a live
  region so the change is announced. Command menu already does.
