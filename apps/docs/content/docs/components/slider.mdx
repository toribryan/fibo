## When to use it

Use Slider when the rough position matters more than the exact number, like
volume, brightness or a price range. One thumb picks a value, two pick a
range, and arrows, Page Up and Page Down, Home and End all move it.

## Installation

<Install name="slider" exports={["Slider", "SliderLabel", "SliderValue"]} />

## Range

Two thumbs, each named through `thumbLabels`.

<Preview>
  <div className="w-full max-w-sm">
    <Slider
      defaultValue={[20, 80]}
      thumbLabels={["Minimum price", "Maximum price"]}
    />
  </div>
</Preview>

## With label and value

`SliderLabel` and `SliderValue` go inside the slider, on one row above the
track. The label names the thumb; the value is formatted with `format`, here
as a percentage.

<Preview>
  <div className="w-full max-w-sm">
    <Slider defaultValue={[60]} format={{ style: "unit", unit: "percent" }}>
      <SliderLabel>Brightness</SliderLabel>
      <SliderValue />
    </Slider>
  </div>
</Preview>

## Accessibility

- Each thumb is announced as a slider with its value. Name it with
  `aria-label`, or with `thumbLabels` for a range.
- Arrow keys move one step, Page Up and Page Down move ten, and Home and End
  jump to the minimum and maximum.
- When the bare number isn't meaningful, like a price, pass `format` with
  `Intl.NumberFormatOptions`, such as a currency.
- The thumb shows a focus ring on keyboard focus, and on hover as a drag cue.
