## When to use it

Use Chat composer for writing a message in a conversation. Type / in the
example to open its commands. Enter sends, Shift+Enter breaks the line, and
the text box grows with the draft.

A provider holds the draft and its actions, and every part reads it from
context. `LocalChatComposerProvider` keeps the draft in component state;
`ChatComposerProvider` takes external state and actions from a store, a
server or a sync layer. There are no boolean feature props: drag and drop,
emoji, commands, dictation and suggested replies are parts. Render one to
enable it, omit it to disable it.

## With attachments

Picked or dropped files show in the header as Attachment parts: images as
thumbnails, other files as chips. Each shows its upload, and send waits until
every one is ready.

can go down to 160px with `min-w-40`.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Compose variants from parts instead of adding props. Edit, thread reply and forward are compositions of the same parts.",
    <>
      Keep state out of the parts. For a draft that survives reloads or syncs
      across devices, replace <code>LocalChatComposerProvider</code> with a{" "}
      <code>ChatComposerProvider</code> fed by your store.
    </>,
    <>
      Wrap everything that needs the draft in the provider. A send button
      outside the frame works as long as it is inside the provider.
    </>,
    <>
      Omit <code>ChatComposerCommonActions</code> when a composer needs a
      different set, and list its actions explicitly.
    </>,
    <>
      Wrap the whole conversation panel in <code>ChatComposerDropZone</code>, so
      files can land anywhere on it.
    </>,
    <>
      Render <code>ChatComposerCommandMenu</code> to turn slash commands on.
      Without it, / is just a character and the command button types one.
    </>,
    "Put suggested replies in the header. They fill the draft and never send on their own.",
    "Below 240px, use the one-row layout or leave out Common actions. The frame's minimum width stops the footer overlapping; it does not make the composer fit.",
    <>
      Return a promise from <code>onSubmit</code> for async sends. The send
      button shows busy, and a rejection keeps the draft.
    </>,
  ]}
/>

## Accessibility

- The text box is named Message by default. Pass `aria-label` for a more
  specific name, such as Edit message.
- Icon buttons are named by their label, which is also their tooltip. The send
  button is named Send.
- Enter sends and Shift+Enter breaks the line. Enter that confirms an input
  method editor composition never sends.
- Each attachment has a Remove button named after the file. A loading one is
  aria-busy, and a failed one offers Retry.
- Typing / opens the command menu as a dialog with focus in its search. Escape
  closes it and returns to the text box, with the slash left out of the draft.
- The emoji grid takes focus on its first emoji. Arrow keys move through it,
  Enter picks, and focus returns to the text box.
- The dictation button is a toggle: aria-pressed is true while it listens.
  Escape also stops it, and focus returns to the text box at the end of the
  dictated words.
- When dictation fails, the reason shows in the mic's tooltip and is read out
  through a status region.
- On touch, the + is named More actions and opens a sheet titled Add to
  message. Focus moves into the sheet, and its rows read their full labels.
- On touch, Return adds a line, and the keyboard's Return key says so through
  enterkeyhint. The send button is the only way to send.
- Dictation uses the browser's speech recognition. Chrome sends the audio to
  Google to transcribe, so say so where privacy matters, or pass your own
  engine to recognition.
- Suggested replies are buttons. Picking one fills the draft and focuses the
  text box; it never sends.
- Dropping files is a shortcut for the attach button, which works from the
  keyboard. Give both the same `accept`.
- The send button is aria-busy while sending. Its progress ring holds still
  under reduced motion.
- After a send, focus returns to the text box.
