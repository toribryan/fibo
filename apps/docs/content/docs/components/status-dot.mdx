## When to use it

Use Status dot for presence: present, away or offline. It's placed by the
Avatar, Sticker avatar or Badge it sits in, and each status has its own shape,
so it reads without color. A page-colored disc behind the mark keeps a clear
edge on a photo or a sticker. For the state of a thing, such as Paid or
Failed, use a Badge.

## Status by shape

Present is a dot, away a crescent, offline a ring. `variant="mono"` draws the
marks in the text color, for places where color would compete, such as a
dense list.

## On avatars

Pass it as a child. Avatar pins it to the corner and matches its size;
Sticker avatar sets it on the paper, turned against the tilt, and adds its
label to the sticker's name.

## Accessibility

- The status is in a visually hidden span, read after whatever comes before
  it: the photo's alt in an Avatar, the name in a Sticker avatar.
- A Sticker avatar is one image to screen readers, so the dot's label joins
  its name through aria-labelledby: Ana Ruiz, Away.
- Shape carries the status as well as color, so it holds for color blindness
  and in mono.
