## When to use it

Use Kbd for a key or keyboard shortcut, in running text or beside the command
it triggers. It renders a `<kbd>` element and sits on the text line without
changing its height.

## Installation

<Install name="kbd" exports={["Kbd", "KbdGroup"]} />

## Shortcut

KbdGroup joins keys into a combination, as HTML nests `<kbd>` for a shortcut.
Symbol keys such as Command take an icon with visually hidden text.

<Preview>
  <KbdGroup>
    <Kbd>
      <CommandIcon aria-hidden="true" />
      <span className="sr-only">Command</span>
    </Kbd>
    <Kbd>K</Kbd>
  </KbdGroup>
</Preview>

## Accessibility

- Screen readers read the key's text. Give an icon key visually hidden text
  with its name, such as “Command”.
- Mark the icon itself `aria-hidden`, so only the name is read.
- Not interactive. Never takes focus or responds to clicks.
