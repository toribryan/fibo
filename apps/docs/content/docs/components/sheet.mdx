## When to use it

Use Sheet for a focused task that needs room, such as editing a record or
setting filters on a phone. It slides in from any edge and closes on Escape,
an outside click, the close button, or a swipe back the way it came. Text in
SheetBody is selectable without dragging the sheet.

`side` goes on Sheet, not SheetContent as in shadcn, because it also sets the
swipe-to-close direction. Always include a SheetTitle.

## Guidelines

  guidelines={[

## Accessibility

- The panel is a modal dialog named by SheetTitle and described by
  SheetDescription.
- Focus moves in on open, stays inside while open, and returns to the
  trigger on close.
- Swiping is never the only way out: Escape, an outside click and the close
  button all close it.
- Name an icon-only trigger with aria-label, such as “Filters”.
- With reduced motion on, it appears and disappears without sliding.
