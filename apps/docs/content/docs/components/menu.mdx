## When to use it

Use Menu for a short list of actions opened from a button, such as More
actions on a toolbar or a table row's actions. It opens by click, Enter, Space
or the down arrow, and Escape closes it and returns focus. To pick a value for
a form, use Select.

## Row actions

An icon-only trigger at the end of a row. Its label names the row, so each
trigger in a table is distinct.

## Checkbox and radio items

Checkbox items toggle, such as a table's visible columns, and the menu stays
open while toggling. Radio items pick one choice from a group, such as the
sort order.

## Accessibility

- The trigger is a button with `aria-haspopup`, and the list is a menu of
  `menuitem`, `menuitemcheckbox` and `menuitemradio`, following the APG menu
  button pattern.
- Name an icon-only trigger with `aria-label`, and include the row it acts
  on, such as “Actions for Maya Okafor”.
- Icons in items need no extra markup: lucide hides them from screen readers,
  and the item's text is its name.
- Focus returns to the trigger when the menu closes, whether an item was
  chosen or Escape was pressed.
- MenuShortcut is hidden from screen readers so it isn't read as part of the
  item's name. It's a hint only: wire up the key separately, then add
  `aria-keyshortcuts` to the item.
