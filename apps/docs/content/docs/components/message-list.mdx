## When to use it

Use Message list for a conversation. Each run of one person's messages groups
under a heading with their name and picture, and a group ends when the author
or day changes, or enough time passes. The whole list is one tab stop: arrow
keys move between messages, Enter enters one and Escape leaves it.

Pass the whole conversation, oldest first. Grouping reads each message's
neighbors, so a list of only the visible rows starts a new group at the top
of every scroll. To virtualize, call `groupMessages` on the full list and
render from its result.

## Rolling or fixed window

Five messages, four minutes apart. Rolling, they stay one group. Fixed, a new
group starts five minutes after the first.

## Unread

`unreadFrom` names the first unread message. The divider above it is red with
a "New" label, so it doesn't rely on color alone, and it breaks the group.
Freeze the value when the conversation opens so the line stays put while
people read; clear it when they send a message, press Escape or mark the
conversation read.

## Accessibility

- The list is a `role="log"`, so screen readers announce new messages. The
  ARIA feed pattern suits browsing a long stream but announces nothing new on
  its own.
- Each group's author is a heading, so screen reader users can jump from
  author to author. Set `headingLevel` to fit the page's outline.
- Every message is an article named with its author and time, since a screen
  reader user can land mid-group and miss the heading.
- The list takes one Tab stop. Arrow keys, Home and End move between
  messages. Enter, or a click, moves focus to the first control inside a
  message; Escape returns to the message. Controls inside a message, including
  ones added later, stay out of the tab order until then.
- If the focused message is removed, focus moves to the message that takes
  its place, never to the page.
- On later messages in a group, the time sits in a `time` element and shows
  on hover or focus.
- Day and custom dividers are separators named by their label.
