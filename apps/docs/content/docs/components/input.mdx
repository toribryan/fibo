## When to use it

Use Input for a single line of free text: a name, an email, a search term. It
fills the width of its container and takes every native `input` prop and
type. For more than one line, use a Textarea.

## Sizes

`size="sm"` matches a small Select or Button in dense forms and toolbars.
`size` sets the height instead of the native width; set width with
`className`.

<Preview>
  <div className="flex w-full max-w-xs flex-col gap-3">
    <Input aria-label="Default size" placeholder="Default" />
    <Input size="sm" aria-label="Search" placeholder="Search" />
  </div>
</Preview>

## Invalid and disabled

`aria-invalid` turns the border and the focus ring destructive. `disabled`
dims it and blocks the pointer.

<Preview>
  <div className="flex w-full max-w-xs flex-col gap-3">
    <Input aria-label="Email" aria-invalid defaultValue="not-an-email" />
    <Input aria-label="Locked" disabled defaultValue="Can't edit this" />
  </div>
</Preview>

## Accessibility

- Connect the label with `htmlFor` and `id`.
- Mark errors with `aria-invalid` and point to the message with
  `aria-describedby`.
- Add `autoComplete` for personal details so browsers and password managers
  can fill them.
