## When to use it

Use Typing indicator below the messages in a conversation to show who's
writing a reply. It names up to three people, then says "Several people are
typing…". It takes people as data and omits the current user, joins names
with `Intl.ListFormat` for the locale, announces the sentence once it
settles, and keeps its height when nobody is typing so messages above don't
jump.

## Several people

Past `maxNames`, nobody is named, as Discord does from four people on.

## Translated

A Spanish formatter with `locale="es"`. `format` gets `{ count, names, list }`
and returns the whole sentence; `names` is empty once `count` passes
`maxNames`. Write one sentence per case instead of building it from fragments
like `name + " and " + other`, since plural forms, verbs and word order vary
by language. `Intl.ListFormat` supplies "y".

## Accessibility

- The sentence goes to a polite `role="status"` region, present from the
  start and outside the message log so it doesn't mix with new messages.
- Announcements wait for the sentence to hold still for `announceDelay` ms
  (1500 by default), so a burst of starts and stops is heard once.
- When everyone stops, the region empties silently.
- The dots and visible text are hidden from screen readers, which hear the
  status region, with names in full.
- The dots can run past five seconds, so under reduced motion they hold still
  as a plain ellipsis (WCAG 2.2.2).
