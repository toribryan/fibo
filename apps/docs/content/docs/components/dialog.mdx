## When to use it

Use Dialog for a short task over the page, such as editing a few fields. It
closes on Escape, an outside click, the corner button or any DialogClose.
DialogTitle is required; it names the dialog for screen readers. For an
irreversible confirmation, use Alert dialog.

## Long content

DialogBody scrolls when content exceeds the viewport; title and footer stay
fixed, keeping the footer in reach.

<Preview>
  <Dialog>
    <DialogTrigger render={<Button variant="outline" />}>
      Read the terms
    </DialogTrigger>
    <DialogContent>
      <DialogHeader>
        <DialogTitle>Terms of service</DialogTitle>
        <DialogDescription>{"Last updated October 2026."}</DialogDescription>
      </DialogHeader>
      <DialogBody className="flex flex-col gap-3 text-sm text-muted-foreground">
        {Array.from({ length: 12 }, (_, index) => (
          <div key={index}>
            {`${index + 1}. The workspace belongs to the people who make it. We keep what you write private, back it up every night, and hand it all back in a standard format whenever you ask.`}
          </div>
        ))}
      </DialogBody>
      <DialogFooter>
        <DialogClose render={<Button />}>Got it</DialogClose>
      </DialogFooter>
    </DialogContent>
  </Dialog>
</Preview>

## Guidelines

<UsageGuidelines
  guidelines={[
    "Use for a short task tied to the page behind. Multi-step tasks or browsing belong on a page or in a Sheet.",
    "Title it after the task; say what saving does in the description.",
    "Put the main action last in the footer. On phones it stacks on top, nearest the thumb.",
    "Don't open a dialog from a dialog.",
    "Don't use one for a message that needs no answer. A Toast does that without taking focus.",
  ]}

## Accessibility

- A modal dialog named by DialogTitle and described by DialogDescription.
- Focus moves to the first control on open, is trapped while open, and
  returns to the trigger on close.
- Escape closes it from anywhere inside. The page behind is inert and
  doesn't scroll.
- The corner button is named Close for screen readers.
