## When to use it

Use Attachment for each file someone has added, in a chat draft, a form or a
sent message. `type` picks the shape: `file` is a one-line chip with the name
and size, `image` is a 56px thumbnail. It shows an upload but never runs one;
whoever runs the upload owns `status`.

## Statuses

`status` follows an upload: `ready`, `loading` or `error`. On error the text
replaces the size, and retry sits before remove.

<UsageGuidelines
  guidelines={[

## Accessibility

- Remove and retry are buttons named with the file, such as Remove
  token-audit.pdf.
- A loading attachment sets `aria-busy` and reads Uploading.
- The image's alt text is the file name. On error, the tile's retry button
  reads the error.
- The loading spinner stops under reduced motion.
