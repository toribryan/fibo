## When to use it

Use Checkbox to turn one option on or off, or to pick any number from a list,
when the change applies on form submit. For a setting that applies
immediately, use a switch.

## Installation

<Install name="checkbox" exports={["Checkbox"]} />

## States

Checked, unchecked, indeterminate and disabled. `indeterminate` shows a dash
for a partly-on group, such as select all with some rows selected, and screen
readers hear "mixed".

## Accessibility

- Connect the label with `htmlFor` and `id`, or wrap the checkbox in the
  Label.
- The hit area extends past the 16px box on every side, to the 24px minimum
  target.
- Mark errors with `aria-invalid`. The box turns destructive and keeps its
  focus ring.
