## When to use it

Use Table for data compared across rows: a native HTML table at one compact
density, 36px headers and 40px rows. It scrolls sideways in its own box when
wider than the page. For selection, pinned columns and bulk actions, use Data
table, which is built on it.

## Accessibility

- Give the table a name: a TableCaption, or aria-label or aria-labelledby on
  Table.
- Use TableHead for every column header, so each cell is announced with its
  column.
- While the table overflows, the scroll box is a focusable region that
  scrolls with the arrow keys. It takes the table's aria-label or caption, so
  the name is announced once.
- Header labels use foreground text on the muted band. Muted text there would
  be 4.34:1, under AA.
