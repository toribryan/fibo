## When to use it

Use Input group when an icon, text, a Kbd or a Button belongs inside the
field. The group draws the border, focus ring and invalid state around the
addons, and pressing an addon focuses the input. Put the label outside the
group, in a FieldLabel or `aria-label`.

## Ghost, in a menu

`variant="ghost"` drops the border and background, so the popup is the field.
Used by Command menu and Filter menu.

## Guidelines

<UsageGuidelines
  guidelines={[
    "One addon on each side at most. More reads as a toolbar, not a field.",

    "Use the ghost variant only where the surface around it marks the field, such as a popup's header.",

## Accessibility

- The group has the group role; the input needs its own name, from a
  FieldLabel or aria-label.
- Hide decorative icons in addons with aria-hidden.
- Pressing an addon focuses the input without blurring it first, so the caret
  stays put. Buttons in an addon work as usual.
