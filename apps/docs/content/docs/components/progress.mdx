## When to use it

Use Progress for a task that takes more than a couple of seconds, such as an
upload. Pass a `value` from 0 to 100 when the total is known, or
`value={null}` while it isn't. A label and formatted value sit on one row
above the bar. The fill glides between values; under reduced motion it
jumps. For content loading into a layout, use Skeleton.

## Circle

`type="circle"` draws a ring in the current text color, sized `xs` to `lg`:
12, 16, 20 and 24 pixels. With a `value` the arc shows progress; with
`value={null}` a quarter arc turns, holding still under reduced motion. Name
it with `aria-label`, since a circle has no room for a label.

## In a button

A small circle replaces a button's icon while its action runs. The button's
text or `aria-label` says what's happening, so the circle is hidden from
screen readers. Used by Toast and Chat composer.

<Preview>
  <Button disabled>
    <Progress type="circle" size="sm" value={null} aria-hidden="true" />
    {"Saving"}
  </Button>
  <Button size="icon" aria-label="Sending" disabled>
    <Progress type="circle" size="sm" value={null} aria-hidden="true" />
  </Button>
  <Button size="icon" aria-label="Send">
    <ArrowUpIcon />
  </Button>
</Preview>

## Accessibility

- The root is a `progressbar` with `aria-valuenow`. ProgressLabel names it;
  without one, pass `aria-label`.
- Most screen readers don't announce each change. When the task finishes,
  say so in the label or with a toast.
- Pass `getAriaValueText` when a percentage isn't the clearest reading, such
  as “3 of 12 files”.
