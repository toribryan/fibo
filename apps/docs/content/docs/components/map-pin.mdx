## When to use it

Use Map pin for a point on a map: a dot, an icon or a pill with a short label
such as a price. It brings no map; Mapbox, MapLibre or any library that
places a DOM element on its map positions it and moves it as the map pans and
zooms. It lifts part way on hover, then opens a preview card on click or tap
and stays open, so the card can hold links and actions. Escape or a click
elsewhere closes it and returns focus.

`label` names the pin for screen readers. Every pin needs one, even when it
shows a price.

## Label pins

`type="label"` shows a short value in a pill. The open pin fills in, so it's
clear which preview it owns.

## Colors

`variant` takes fibo's status colors, here marking whether each place is
open. The status is also in each pin's `label` and meta, so it doesn't rest
on color alone.

## Accessibility

- Each pin is a button named by its label, and says it opens a dialog. A
  label pin showing a price is still announced by the place's name.
- Enter or Space opens the preview and moves focus into it. Escape closes it
  and returns focus to the pin.
- The preview is a dialog named by the pin's label, so screen readers
  announce which place they're in.
- A dot is 16px to look at but takes presses across 32px, above the 24px
  minimum target.
- Color never stands alone: put the status in the pin's label, which screen
  readers announce, and in the preview.
- With reduced motion, the pin changes without animating and the card fades
  in place.
