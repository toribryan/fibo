## When to use it

Use Separator when groups would run together without a rule. Prefer space
first. It runs across its container, or down its row's height, and children
make a labeled rule: line, label, line.

## Installation

<Install name="separator" exports={["Separator"]} />

## Vertical

Between items in a row, such as toolbar actions. Takes the row's height.

  <div className="flex h-5 items-center gap-3 text-sm">
    <span>Edit</span>

    <span>Share</span>
    <Separator orientation="vertical" />
    <span>Delete</span>
  </div>
</Preview>

## With a label

Children sit between two lines, such as a date in a conversation.

## Accessibility

- The separator role and aria-orientation make screen readers announce a
  break.
- A separator's children aren't read, so a text label becomes its
  aria-label. Pass aria-label when the label isn't plain text.
