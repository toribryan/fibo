## When to use it

Use Badge for a short, non-interactive label for a status, category or count,
placed next to what it describes. Say the state in the label; the variant
only reinforces it. It isn't in the tab order, so anything that responds to a
click is a Button.

## Variants

Three neutral variants, `default`, `secondary` and `outline`, and four status
tints: `destructive` for states that need action, `success`, `warning` and
`info`.

## With a status dot

A badge can lead with an icon or a Status dot. Give the dot `label={null}`
when the badge's text already says the status.

<Preview>
  <Badge variant="outline">
    <StatusDot status="present" label={null} />
    Online
  </Badge>
  <Badge variant="secondary">
    <StatusDot status="away" label={null} />
    Away
  </Badge>
</Preview>

## Guidelines

<UsageGuidelines
  guidelines={[

## Accessibility

- If the badge only makes sense next to its neighbor, give the pair context,
  for example with `aria-describedby`.
- The variant never carries meaning alone. The text says it too.
