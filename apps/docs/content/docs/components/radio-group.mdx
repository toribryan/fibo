## When to use it

Use Radio group when people pick exactly one option and should see every
option at once. Arrow keys move the selection and the group is one Tab stop.
For longer lists, or tight space, use Select.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Use for two to about six options that people should compare side by side.",
    "For longer lists, or tight space, use Select.",
    "Start with a sensible option chosen. A radio group can't be cleared once someone picks.",
    "Order options logically: smallest to largest, most to least common, or alphabetically.",
    "Stack options in a column. Use a row only for two or three short labels.",

## Do's and don'ts

<ComponentRules
  rules={[
    {
      positive: {
        component: (
          <RadioGroup defaultValue="monthly" aria-label="Billing">

## Accessibility

- Name the group with `aria-label`, or wrap it in a fieldset with a legend,
  so screen readers announce what the options are for.
- Tab enters the group on the chosen option and leaves in one step. Arrow
  keys move between options and choose as they go.
- Connect each Label with `htmlFor` and `id`. The label is part of the hit
  area.
- The dot marks the chosen option alongside the fill, so it doesn't rely on
  color alone.
