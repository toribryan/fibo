## When to use it

Use Textarea for answers that may run past one line: notes, descriptions,
messages. It grows with its content through `field-sizing: content`, from a
64px minimum height, so it never needs its own scrollbar.

## States

`aria-invalid` turns the border and the focus ring destructive. `disabled`
dims the textarea and blocks the pointer.

## Accessibility

- Mark errors with `aria-invalid` and link the message with
  `aria-describedby`.
- Don't disable resizing and auto-grow together in a fixed-height container;
  content gets clipped.
