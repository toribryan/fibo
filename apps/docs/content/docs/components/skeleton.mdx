## When to use it

Use Skeleton for content that loads into a known layout. It's one styled
`div`, sized and shaped with classes into a line, a circle or a card, with a
slow pulse that stops under reduced motion. Match the size and shape of the
incoming content so the layout doesn't shift when it arrives.

## Accessibility

- Skeletons have no role and aren't announced. Set `aria-busy="true"` on the
  region that's loading, and remove it when the content arrives.
- For a long load, add a visually hidden status message, such as “Loading
  projects”.
- The pulse stops under prefers-reduced-motion.
