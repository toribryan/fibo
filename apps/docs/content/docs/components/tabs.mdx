## When to use it

Use Tabs to switch between views of one subject in place, such as sections of
a settings page. One tab is active and only its panel shows. The list is a
segmented control with a sliding pill by default, in `sm` (32px) or `default`
(36px) to match Button and Input. A row that overflows scrolls sideways
instead of wrapping, keeping the active tab in view.

## Line

`variant="line"` drops the track; the active tab takes the text color and a
bar beneath. For the top of a page or card, where a segmented control is too
heavy.

  <TabsLineDemo />
</Preview>

## Vertical

`orientation="vertical"` on `Tabs` puts the list beside the panels. The line
variant's bar moves to the start edge; up and down arrows move between tabs.

  <TabsVerticalDemo />
</Preview>

## With icons and counts

Icons and Counts go in a trigger as children. Hide the icon with
`aria-hidden`; give the Count a `label` so it reads as more than a bare
number.

## Guidelines

<UsageGuidelines
  guidelines={[
    "Use for views of one subject that people move between freely. Sequential steps need a stepper; site pages need links.",
    "Labels are one or two words, sentence case, nouns not actions.",
    "Segmented control for two to five short options near the content; line variant for sections of a page or card.",
    "Keep the set stable. Disable a tab that can't be used yet rather than removing it.",
    "Give every tab an icon or none; a partial set looks unfinished.",
  ]}
/>

<Tip>
  Panels unmount when hidden. `keepMounted` on `TabsContent` preserves a panel's
  state, such as a half-filled form, while another tab is open.
</Tip>

## Accessibility

- Name the list with `aria-label`, or `aria-labelledby` pointing at a heading,
  so screen readers announce what the tabs choose between.
- Tab focuses the active tab; Tab again moves to the panel. In the list, arrow
  keys move between tabs (left and right, or up and down when vertical),
  wrapping at the ends. Home and End go to the first and last.
- Arrows only move focus; Enter or Space activates. This is Base UI's default,
  `activateOnFocus={false}`, which suits panels that are slow to render. Set
  it on `TabsList` to switch as focus moves.
- Each tab is linked to its panel: the panel is named by its tab, and the tab
  names the panel it controls.
- The active tab is marked by a raised pill or a bar as well as text color.
  Hover changes only the text color or adds a muted fill, never the pill or
  bar.
- The pill slides between tabs in 200ms, and jumps under reduced motion.
