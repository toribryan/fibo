## When to use it

Use Tooltip for a short label shown on hover or focus, such as an icon
button's name or why something is locked. It opens on hover after a short
delay and at once on keyboard focus, Escape closes it without moving focus,
and it flips to stay on screen.

neighbors open without the delay. Each tooltip gives the button name and
shortcut.

so keyboard users reach the reason too.

## Accessibility

- Screen readers don't read the tooltip. Put the same words on the trigger
  with `aria-label`, or in visible text linked with `aria-describedby`.
- The trigger must be focusable so keyboard users can open it. A disabled
  button isn't; use `aria-disabled`, or put the tooltip on a separate
  focusable icon.
- Touch screens have no hover, so nothing should exist only in a tooltip.
- Opens on focus, closes on Escape, and stays open while the pointer is over
  it, per WCAG 1.4.13.
