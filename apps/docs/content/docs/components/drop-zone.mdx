## When to use it

Use Drop zone to let people drop files onto an area, usually a whole
conversation panel, so the target is easy to hit. It splits dropped files by
`accept` into `onDropFiles` and `onRejectFiles`, ignores text and links
dragged across it, and never changes what it covers. In a chat,
`ChatComposerDropZone` wires it to the composer for you.

## Accessibility

- Dragging needs a pointer, so a file picker such as the composer's Attach
  files is the keyboard path.
- The overlay is `aria-hidden`: it only mirrors a drag already in progress.
