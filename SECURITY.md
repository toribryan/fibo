# Security policy

fibo ships React component source through a shadcn registry. Code copied into
your project becomes yours, so keep it up to date by re-running
`pnpm dlx shadcn@latest add @fibo/<name>` when a fix lands.

## Supported versions

Only the latest version on the `main` branch, and the registry served from
https://fibo.toribryan.com, receive fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/toribryan/fibo/security/advisories/new)
with steps to reproduce and the affected component. You can expect a reply
within a week, and a fix or a plan for one soon after.
