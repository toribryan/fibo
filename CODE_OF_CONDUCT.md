# Code of conduct

fibo follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work, not
the person. Harassment, personal attacks and discriminatory language are not
welcome in issues, pull requests, discussions or any other project space.

## Reporting

If someone's behavior concerns you, contact the maintainer privately through
[GitHub](https://github.com/toribryan). Reports are kept confidential, and the
maintainer may remove, edit or reject comments, commits and issues that break
this code, or block a contributor from the project.
