# Plans

One file per piece of work that needs a decision before the code is written.
Number them in order and never reuse a number, so a plan can be referenced from
a commit or pull request by its number alone.

```
plans/
  001-short-name.md
  002-short-name.md
```

Each plan answers four questions: what is changing, why now, what the options
were, and what was chosen. Keep the file after the work ships. It is the record
of why the code looks the way it does.
